# Full Themes (F-35) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A theme becomes a self-contained package (colours, fonts, desktop / Lister / requester background pictures, icons, a sounds container) that can be built from the current settings (Save), packed (Export), installed (Import) and edited in a dedicated Theme Editor window.

**Architecture:** Extend the existing theme folder format (`theme.json` gains `fonts` and `surfaces`; `Settings` gains the same two defaulted fields). CSS for fonts and pictures is generated by pure functions in `opusdm-ui` and appended to the stylesheets that already exist. One writer (`writer::write_theme`, staging folder then swap) serves both Save theme and the Theme Editor, which edits a `ThemeDraft` plus pending file operations and only touches disk on Save; Export zips a theme folder through one shared packer crate also used by `xtask`.

**Tech Stack:** Rust 2021, GTK4 (gtk4-rs 0.10), serde / serde_json, zip, walkdir, tempfile, fontconfig through a tiny FFI declaration.

**Spec:** `docs/superpowers/specs/2026-10-01-full-themes-design.md`

## Global Constraints

- Code, comments and docs are English. Never write the long dash character, always `-`.
- Constants are `UPPER_SNAKE_CASE`. Every function and method has a doc comment. Early returns at the top, one line when possible.
- No new tool or dependency without need: the only new crate is `crates/themepack` (shared packer).
- `theme.json` holds values and relative file names only, never absolute paths.
- A theme is a partial override: a field is applied only where the theme sets it.
- Old `settings.json` and old `theme.json` files must still load (`#[serde(default)]`).
- Sounds are a container only: `sounds/` is copied, never played.
- Run tests with `cargo test -p <crate>`. Never use `git commit --no-verify`; if a hook fails fix the cause. Do not push. No AI attribution lines in commit messages.
- Pre-existing quirk, do not touch: `TODO.md` line for F-15 contains a literal `\n`.

## Review Focus

Failure modes the spec implies but a first reading would miss; each has a test in the named task (item 7 is covered by the manual checklist in Task 11, GTK widgets have no unit tests).

1. An imported `theme.json` with an image name like `../../etc/x` or `a/b.png` must not resolve outside `backgrounds/` (Task 1: `is_plain_file_name`).
2. A font family or image path containing `"`, `\`, `;`, `}` or a newline must not break out of the generated CSS (Task 2: `css_quote`, `file_url` tests).
3. Saving a theme over the slug it was built from must not lose icons / fonts / sounds (Task 5, staging then swap).
4. A failed Save leaves neither a half-written theme nor a stray staging folder (Task 5).
5. A missing or relative background image must not produce a CSS rule or a crash; a Lister picture must not hide the file text (rows become semi-transparent) (Tasks 2 and 3).
6. Opening a theme whose `theme.json` is hand-edited and unparseable must not let the editor overwrite it with an empty one (Task 8: `load_draft` errors).
7. The editor must not report unsaved changes just because a widget normalised a value (hex case), and must carry through parts it does not edit (behaviour, desktop metrics) (Task 9: each tab compares against its `initial` reading).
8. Adding a file and removing it in the same session must leave no pending operation; the default theme can never be deleted (Task 8).

```rust
//! CSS for a theme's fonts and background pictures. Pure string building, no
//! GTK, so every rule is unit-testable. Values coming from a theme (font
//! names, image paths) are escaped here and never spliced in raw.

use opusdm_ipc::desktop::ImageFit;
use opusdm_ipc::look::{FontSpec, SurfaceImage};
use opusdm_ipc::Settings;
use std::path::Path;

/// CSS class carried by every requester / dialog window, so a theme picture
/// can target them (and only them).
pub const REQUESTER_CLASS: &str = "opus-requester";

/// Opacity of the file rows when the Lister has a background picture, so the
/// picture shows through without hiding the text.
pub const ROW_ALPHA_WITH_PICTURE: f32 = 0.6;

/// Largest font size a theme may request, in points.
const MAX_FONT_SIZE: u32 = 72;

/// Quote `s` as a CSS string: backslash and double quote are escaped and
/// control characters (newlines included) are dropped.
fn css_quote(s: &str) -> String {
    let mut out = String::from("\"");
    for c in s.chars() {
        match c {
            '"' | '\\' => {
                out.push('\\');
                out.push(c);
            }
            c if c.is_control() => {}
            c => out.push(c),
        }
    }
    out.push('"');
    out
}

/// A CSS `url()` for an absolute file path, percent-encoding every byte that
/// is not alphanumeric or one of `/ - _ . ~`.
fn file_url(path: &Path) -> String {
    let mut out = String::from("url(\"file://");
    for b in path.to_string_lossy().bytes() {
        if b.is_ascii_alphanumeric() || b"/-_.~".contains(&b) {
            out.push(b as char);
        } else {
            out.push_str(&format!("%{b:02X}"));
        }
    }
    out.push_str("\")");
    out
}

/// The `background-*` declarations that realise `fit`.
fn fit_declarations(fit: ImageFit) -> &'static str {
    match fit {
        ImageFit::Fill => "background-repeat: no-repeat; background-position: center; background-size: cover;",
        ImageFit::Fit => "background-repeat: no-repeat; background-position: center; background-size: contain;",
        ImageFit::Center => "background-repeat: no-repeat; background-position: center; background-size: auto;",
        ImageFit::Tile => "background-repeat: repeat; background-position: top left; background-size: auto;",
    }
}

/// A rule setting the font family and size of `selector`, or an empty string
/// when `font` sets neither.
pub fn font_rule(selector: &str, font: &FontSpec) -> String {
    let mut decls = String::new();
    let family = font.family.trim();
    if !family.is_empty() {
        decls.push_str(&format!("font-family: {}; ", css_quote(family)));
    }
    if font.size > 0 {
        decls.push_str(&format!("font-size: {}pt; ", font.size.min(MAX_FONT_SIZE)));
    }
    if decls.is_empty() {
        return String::new();
    }
    format!("{selector} {{ {decls}}} ")
}

/// A rule painting `surface`'s picture on `selector`, or an empty string when
/// there is no picture, its path is not absolute, or the file is missing (the
/// last case is logged).
pub fn surface_rule(selector: &str, surface: &SurfaceImage) -> String {
    let Some(path) = surface.image_path.as_ref() else { return String::new() };
    if !path.is_absolute() {
        return String::new();
    }
    if !path.is_file() {
        opusdm_ipc::err_log!("ui", "background picture not found: {}", path.display());
        return String::new();
    }
    format!("{selector} {{ background-image: {}; {} }} ", file_url(path), fit_declarations(surface.fit))
}

/// The theme look shared by every OpusDM window: the UI font and the
/// requester picture. The Lister adds its list font and list picture on top
/// (see `opusdm-lister`'s `theme.rs`).
pub fn ui_look_css(settings: &Settings) -> String {
    let mut css = font_rule("window", &settings.fonts.ui);
    let picture = surface_rule(&format!("window.{REQUESTER_CLASS}"), &settings.surfaces.requester);
    if !picture.is_empty() {
        css.push_str(&picture);
        css.push_str(&format!(
            "window.{REQUESTER_CLASS} box, window.{REQUESTER_CLASS} grid {{ background-color: transparent; }} "
        ));
    }
    css
}
```

```rust
//! Runtime registration of the font files shipped inside a theme, for the
//! current process only (nothing is installed system-wide). Uses fontconfig
//! directly because gtk4-rs does not expose it; pango, already linked by GTK,
//! sits on top of the same fontconfig.

use std::collections::HashSet;
use std::ffi::{c_char, c_int, c_void, CString};
use std::path::{Path, PathBuf};
use std::sync::Mutex;

#[link(name = "fontconfig")]
extern "C" {
    fn FcConfigAppFontAddFile(config: *mut c_void, file: *const c_char) -> c_int;
}

#[link(name = "pangocairo-1.0")]
extern "C" {
    fn pango_cairo_font_map_get_default() -> *mut c_void;
}

#[link(name = "pangoft2-1.0")]
extern "C" {
    fn pango_fc_font_map_config_changed(fontmap: *mut c_void);
}

/// Font files registered so far in this process, so a repaint does not add
/// the same file twice.
static REGISTERED: Mutex<Option<HashSet<PathBuf>>> = Mutex::new(None);

/// The `.ttf` / `.otf` files directly inside `dir`, sorted by name. A missing
/// or unreadable folder yields an empty list.
pub fn font_files(dir: &Path) -> Vec<PathBuf> {
    let Ok(entries) = std::fs::read_dir(dir) else { return Vec::new() };
    let mut files: Vec<PathBuf> = entries
        .flatten()
        .map(|e| e.path())
        .filter(|p| p.is_file())
        .filter(|p| {
            p.extension()
                .and_then(|e| e.to_str())
                .is_some_and(|e| e.eq_ignore_ascii_case("ttf") || e.eq_ignore_ascii_case("otf"))
        })
        .collect();
    files.sort();
    files
}

/// Hand one file to the default fontconfig configuration. True when
/// fontconfig accepted it.
fn register_font_file(path: &Path) -> bool {
    let Ok(c_path) = CString::new(path.to_string_lossy().as_bytes()) else { return false };
    // SAFETY: `c_path` is a valid NUL-terminated string that outlives the
    // call; a null config means "the current configuration".
    unsafe { FcConfigAppFontAddFile(std::ptr::null_mut(), c_path.as_ptr().cast()) != 0 }
}

/// Register every font file of theme `slug` (its `fonts/` folder) with this
/// process and tell pango to re-read the configuration. Returns how many
/// files were newly registered; unreadable files are logged and skipped.
pub fn register_theme_fonts(slug: &str) -> usize {
    let dir = opusdm_ipc::themes::theme_dir(slug).join("fonts");
    let mut guard = REGISTERED.lock().expect("font registry lock poisoned");
    let seen = guard.get_or_insert_with(HashSet::new);
    let mut added = 0;
    for file in font_files(&dir) {
        if seen.contains(&file) {
            continue;
        }
        if register_font_file(&file) {
            seen.insert(file);
            added += 1;
        } else {
            opusdm_ipc::err_log!("ui", "cannot register font file {}", file.display());
        }
    }
    if added > 0 {
        // SAFETY: the default pangocairo font map is a fontconfig map on
        // Linux; a null map is skipped.
        unsafe {
            let map = pango_cairo_font_map_get_default();
            if !map.is_null() {
                pango_fc_font_map_config_changed(map);
            }
        }
    }
    added
}
```

```rust
use std::fs::File;
use std::io::{self, Write};
use std::path::Path;

/// Zip the contents of `src` into `zip_path`. Entries use `/` separators and
/// are sorted by name, so the same folder always yields the same archive
/// layout. The folder itself is not an entry: `manifest.json` ends up at the
/// archive root, as the importer expects.
pub fn pack_theme_dir(src: &Path, zip_path: &Path) -> io::Result<()> {
    if !src.is_dir() {
        return Err(io::Error::new(io::ErrorKind::NotFound, format!("{} is not a folder", src.display())));
    }
    let mut zip = zip::ZipWriter::new(File::create(zip_path)?);
    let options = zip::write::SimpleFileOptions::default();
    for entry in walkdir::WalkDir::new(src).sort_by_file_name() {
        let entry = entry.map_err(io::Error::other)?;
        let rel = entry.path().strip_prefix(src).map_err(io::Error::other)?;
        if rel.as_os_str().is_empty() {
            continue;
        }
        let name = rel.to_string_lossy().replace('\\', "/");
        if entry.file_type().is_dir() {
            zip.add_directory(format!("{name}/"), options).map_err(io::Error::other)?;
        } else {
            zip.start_file(name, options).map_err(io::Error::other)?;
            zip.write_all(&std::fs::read(entry.path())?)?;
        }
    }
    zip.finish().map_err(io::Error::other)?;
    Ok(())
}
```

```rust
//! Writes a theme folder from a [`ThemeDraft`]. The theme is built in a
//! staging folder next to the others and swapped in only on full success, so
//! a failure never leaves a half-written theme and writing over the theme the
//! assets came from cannot lose them. Used by "Save theme" and the Theme
//! Editor.

use opusdm_ipc::desktop::{Background, BackgroundMode};
use opusdm_ipc::look::{Fonts, SurfaceImage, ThemeSurface, ThemeSurfaces};
use opusdm_ipc::themes::{
    is_plain_file_name, theme_dir, themes_dir, valid_slug, CustomThemeData, ThemeBackground, ThemeDesktopMetrics, ThemeManifest,
};
use opusdm_ipc::{Appearance, Behavior, ColorSettings};
use std::fmt;
use std::path::{Path, PathBuf};

/// `manifest.json` `version` written when the draft has none.
const DEFAULT_VERSION: &str = "1";

/// The icon files a theme provides, without the `.png` extension.
pub const ICON_NAMES: [&str; 12] =
    ["archive", "audio", "broken", "code", "dir", "exec", "file", "image", "pdf", "symlink", "text", "video"];

/// Extensions (lower case) accepted for files in `fonts/`.
pub const FONT_EXTS: [&str; 2] = ["ttf", "otf"];

/// Extensions (lower case) accepted for files in `sounds/`.
pub const AUDIO_EXTS: [&str; 6] = ["wav", "ogg", "oga", "mp3", "flac", "opus"];

/// A theme as the editor and Save see it. `None` means the theme does not set
/// that part, so applying it leaves the user's own value. Pictures are
/// absolute paths; the writer copies them into the theme.
#[derive(Debug, Clone, Default, PartialEq)]
pub struct ThemeDraft {
    pub label: String,
    pub author: Option<String>,
    pub version: Option<String>,
    pub colors: Option<ColorSettings>,
    pub appearance: Option<Appearance>,
    pub behavior: Option<Behavior>,
    pub desktop: Option<ThemeDesktopMetrics>,
    pub background: Option<Background>,
    pub fonts: Option<Fonts>,
    pub lister: Option<SurfaceImage>,
    pub requester: Option<SurfaceImage>,
}

/// A change to the files carried by a theme, applied in order on top of the
/// source theme's own files.
#[derive(Debug, Clone, PartialEq)]
pub enum AssetOp {
    AddFont(PathBuf),
    RemoveFont(String),
    AddSound(PathBuf),
    RemoveSound(String),
    /// Overwrite `icons/<name>.png` with `src`.
    ReplaceIcon { name: String, src: PathBuf },
}

/// Why writing a theme failed.
#[derive(Debug)]
pub enum BuildError {
    /// The slug is not a valid theme folder name.
    InvalidName(String),
    /// The draft or an asset operation is not acceptable.
    Invalid(String),
    Io { path: PathBuf, source: std::io::Error },
    Json(serde_json::Error),
}

impl fmt::Display for BuildError {
    fn fmt(&self, f: &mut fmt::Formatter<'_>) -> fmt::Result {
        match self {
            BuildError::InvalidName(n) => write!(f, "invalid theme name: {n:?}"),
            BuildError::Invalid(m) => write!(f, "{m}"),
            BuildError::Io { path, source } => write!(f, "{}: {source}", path.display()),
            BuildError::Json(e) => write!(f, "cannot write theme.json: {e}"),
        }
    }
}

/// Attach `path` to an I/O error.
fn io_err(path: &Path) -> impl FnOnce(std::io::Error) -> BuildError + '_ {
    move |source| BuildError::Io { path: path.to_path_buf(), source }
}

/// Whether `path` has one of `exts` (lower case), ignoring case.
fn has_ext(path: &Path, exts: &[&str]) -> bool {
    path.extension().and_then(|e| e.to_str()).is_some_and(|e| exts.contains(&e.to_ascii_lowercase().as_str()))
}

/// Check a draft and its asset operations before anything is written: the
/// label is not empty, added files exist and have an allowed extension, and
/// names to remove or replace are acceptable.
pub fn validate_draft(draft: &ThemeDraft, ops: &[AssetOp]) -> Result<(), BuildError> {
    if draft.label.trim().is_empty() {
        return Err(BuildError::Invalid("the theme needs a name".to_string()));
    }
    for op in ops {
        let (src, exts): (Option<&PathBuf>, &[&str]) = match op {
            AssetOp::AddFont(p) => (Some(p), &FONT_EXTS),
            AssetOp::AddSound(p) => (Some(p), &AUDIO_EXTS),
            AssetOp::ReplaceIcon { name, src } => {
                if !ICON_NAMES.contains(&name.as_str()) {
                    return Err(BuildError::Invalid(format!("{name:?} is not an icon name")));
                }
                (Some(src), &["png"])
            }
            AssetOp::RemoveFont(n) | AssetOp::RemoveSound(n) => {
                if !is_plain_file_name(n) {
                    return Err(BuildError::Invalid(format!("{n:?} is not a file name")));
                }
                (None, &[])
            }
        };
        let Some(src) = src else { continue };
        if !has_ext(src, exts) {
            return Err(BuildError::Invalid(format!("{} must be one of: {}", src.display(), exts.join(", "))));
        }
        if !src.is_file() {
            return Err(BuildError::Invalid(format!("{} does not exist", src.display())));
        }
    }
    Ok(())
}

/// Write `draft` as theme `slug`, replacing any theme with that slug.
/// `source_slug` names an installed theme whose `icons/`, `fonts/` and
/// `sounds/` are carried over before `ops` are applied. Returns the installed
/// folder.
pub fn write_theme(slug: &str, draft: &ThemeDraft, source_slug: Option<&str>, ops: &[AssetOp]) -> Result<PathBuf, BuildError> {
    if !valid_slug(slug) {
        return Err(BuildError::InvalidName(slug.to_string()));
    }
    validate_draft(draft, ops)?;
    let root = themes_dir();
    std::fs::create_dir_all(&root).map_err(io_err(&root))?;
    let staging = root.join(format!(".{slug}.tmp"));
    if staging.exists() {
        std::fs::remove_dir_all(&staging).map_err(io_err(&staging))?;
    }
    if let Err(e) = stage(slug, draft, source_slug, ops, &staging) {
        if let Err(clean) = std::fs::remove_dir_all(&staging) {
            opusdm_ipc::err_log!("theme-config", "cannot remove {}: {clean}", staging.display());
        }
        return Err(e);
    }
    let dest = theme_dir(slug);
    if dest.exists() {
        std::fs::remove_dir_all(&dest).map_err(io_err(&dest))?;
    }
    std::fs::rename(&staging, &dest).map_err(io_err(&dest))?;
    Ok(dest)
}

/// Build the whole theme inside `dir`.
fn stage(slug: &str, draft: &ThemeDraft, source_slug: Option<&str>, ops: &[AssetOp], dir: &Path) -> Result<(), BuildError> {
    let backgrounds = dir.join("backgrounds");
    let data = CustomThemeData {
        colors: draft.colors.clone(),
        appearance: draft.appearance.clone(),
        behavior: draft.behavior.clone(),
        desktop: draft.desktop.clone(),
        background: draft.background.as_ref().map(|b| theme_background(b, &backgrounds)).transpose()?,
        fonts: draft.fonts.clone(),
        surfaces: theme_surfaces(draft, &backgrounds)?,
    };
    if let Some(source) = source_slug {
        for part in ["icons", "fonts", "sounds"] {
            copy_dir_if_exists(&theme_dir(source).join(part), &dir.join(part))?;
        }
    }
    for op in ops {
        apply_op(op, dir)?;
    }
    let manifest = ThemeManifest {
        name: slug.to_string(),
        label: draft.label.trim().to_string(),
        author: draft.author.clone().filter(|a| !a.trim().is_empty()),
        version: Some(draft.version.clone().filter(|v| !v.trim().is_empty()).unwrap_or_else(|| DEFAULT_VERSION.to_string())),
    };
    write_json(&dir.join("manifest.json"), &manifest)?;
    write_json(&dir.join("theme.json"), &data)
}

/// Serialize `value` to `path` as pretty JSON.
fn write_json<T: serde::Serialize>(path: &Path, value: &T) -> Result<(), BuildError> {
    let text = serde_json::to_string_pretty(value).map_err(BuildError::Json)?;
    std::fs::write(path, text + "\n").map_err(io_err(path))
}

/// The desktop background as a theme section. A picture is only carried when
/// the mode uses it: the path is kept in other modes so switching back is
/// lossless, but it may be stale.
fn theme_background(bg: &Background, backgrounds: &Path) -> Result<ThemeBackground, BuildError> {
    let image = match (bg.mode, &bg.image_path) {
        (BackgroundMode::Image, Some(p)) => Some(copy_picture(p, backgrounds, "desktop")?),
        _ => None,
    };
    Ok(ThemeBackground {
        mode: Some(bg.mode),
        solid: Some(bg.solid.clone()),
        gradient_start: Some(bg.gradient_start.clone()),
        gradient_end: Some(bg.gradient_end.clone()),
        gradient_angle: Some(bg.gradient_angle),
        image,
        image_fit: Some(bg.image_fit),
    })
}

/// The `surfaces` section, or `None` when neither surface is set.
fn theme_surfaces(draft: &ThemeDraft, backgrounds: &Path) -> Result<Option<ThemeSurfaces>, BuildError> {
    if draft.lister.is_none() && draft.requester.is_none() {
        return Ok(None);
    }
    Ok(Some(ThemeSurfaces {
        lister: draft.lister.as_ref().map(|s| theme_surface(s, backgrounds, "lister")).transpose()?,
        requester: draft.requester.as_ref().map(|s| theme_surface(s, backgrounds, "requester")).transpose()?,
    }))
}

/// One surface as a theme section, copying its picture (named `stem.<ext>`).
fn theme_surface(surface: &SurfaceImage, backgrounds: &Path, stem: &str) -> Result<ThemeSurface, BuildError> {
    let image = surface.image_path.as_ref().map(|p| copy_picture(p, backgrounds, stem)).transpose()?;
    Ok(ThemeSurface { image, fit: Some(surface.fit) })
}

/// Copy `src` into `backgrounds/` as `<stem>.<original extension>` and
/// return that file name.
fn copy_picture(src: &Path, backgrounds: &Path, stem: &str) -> Result<String, BuildError> {
    let ext = src.extension().and_then(|e| e.to_str()).unwrap_or("png").to_ascii_lowercase();
    let name = format!("{stem}.{ext}");
    copy_into(src, backgrounds, &name)?;
    Ok(name)
}

/// Copy `src` to `folder/name`, creating `folder`.
fn copy_into(src: &Path, folder: &Path, name: &str) -> Result<(), BuildError> {
    std::fs::create_dir_all(folder).map_err(io_err(folder))?;
    std::fs::copy(src, folder.join(name)).map_err(io_err(src))?;
    Ok(())
}

/// Apply one asset operation inside the staged theme `dir`.
fn apply_op(op: &AssetOp, dir: &Path) -> Result<(), BuildError> {
    match op {
        AssetOp::AddFont(src) => copy_into(src, &dir.join("fonts"), &file_name(src)?),
        AssetOp::AddSound(src) => copy_into(src, &dir.join("sounds"), &file_name(src)?),
        AssetOp::ReplaceIcon { name, src } => copy_into(src, &dir.join("icons"), &format!("{name}.png")),
        AssetOp::RemoveFont(name) => remove_if_exists(&dir.join("fonts").join(name)),
        AssetOp::RemoveSound(name) => remove_if_exists(&dir.join("sounds").join(name)),
    }
}

/// The final component of `path` as a string.
fn file_name(path: &Path) -> Result<String, BuildError> {
    path.file_name().map(|n| n.to_string_lossy().to_string()).ok_or_else(|| BuildError::Invalid(format!("{} has no file name", path.display())))
}

/// Delete `path`; a file that is already gone is fine.
fn remove_if_exists(path: &Path) -> Result<(), BuildError> {
    match std::fs::remove_file(path) {
        Err(e) if e.kind() != std::io::ErrorKind::NotFound => Err(BuildError::Io { path: path.to_path_buf(), source: e }),
        _ => Ok(()),
    }
}

/// Recursively copy `src` to `dst`; a missing `src` is not an error.
fn copy_dir_if_exists(src: &Path, dst: &Path) -> Result<(), BuildError> {
    if !src.is_dir() {
        return Ok(());
    }
    std::fs::create_dir_all(dst).map_err(io_err(dst))?;
    for entry in std::fs::read_dir(src).map_err(io_err(src))? {
        let entry = entry.map_err(io_err(src))?;
        let to = dst.join(entry.file_name());
        if entry.path().is_dir() {
            copy_dir_if_exists(&entry.path(), &to)?;
        } else {
            std::fs::copy(entry.path(), &to).map_err(io_err(&entry.path()))?;
        }
    }
    Ok(())
}
```

```rust
//! "Save theme": capture the current settings as an installed theme. A thin
//! mapping from `Settings` to a [`ThemeDraft`]; the folder is written by
//! `writer::write_theme`.

use crate::writer::{write_theme, BuildError, ThemeDraft};
use opusdm_ipc::themes::{valid_slug, ThemeDesktopMetrics};
use opusdm_ipc::{DesktopSettings, Settings};
use std::path::PathBuf;

/// Everything Save needs.
pub struct BuildRequest<'a> {
    /// Display name.
    pub label: &'a str,
    /// Folder name and `manifest.json` `name`; must pass `valid_slug`.
    pub slug: &'a str,
    /// Installed theme whose `icons/`, `fonts/` and `sounds/` are carried along.
    pub source_slug: &'a str,
    pub settings: &'a Settings,
    pub desktop: &'a DesktopSettings,
}

/// Turn a display name into a theme slug: lower-case ASCII letters and
/// digits, runs of anything else collapsed to a single `-`. `None` when
/// nothing usable is left.
pub fn slugify(label: &str) -> Option<String> {
    let mut slug = String::new();
    for c in label.trim().to_lowercase().chars() {
        if c.is_ascii_alphanumeric() {
            slug.push(c);
        } else if !slug.is_empty() && !slug.ends_with('-') {
            slug.push('-');
        }
    }
    let slug = slug.trim_end_matches('-').to_string();
    valid_slug(&slug).then_some(slug)
}

/// Install the current settings as theme `req.slug`, replacing any theme with
/// that slug. Returns the installed folder.
pub fn save_theme(req: &BuildRequest) -> Result<PathBuf, BuildError> {
    let s = req.settings;
    let draft = ThemeDraft {
        label: req.label.trim().to_string(),
        author: None,
        version: None,
        colors: Some(s.theme.colors.clone()),
        appearance: Some(s.appearance.clone()),
        behavior: Some(s.behavior.clone()),
        desktop: Some(ThemeDesktopMetrics {
            icon_size: Some(req.desktop.icon_size),
            grid_spacing: Some(req.desktop.grid_spacing),
            grid_gap: Some(req.desktop.grid_gap),
        }),
        background: Some(s.theme.background.clone()),
        fonts: Some(s.fonts.clone()),
        lister: Some(s.surfaces.lister.clone()),
        requester: Some(s.surfaces.requester.clone()),
    };
    write_theme(req.slug, &draft, Some(req.source_slug), &[])
}
```

```rust
/// Remove from the staged theme every file that has no business in its
/// `fonts/` (only `.ttf` / `.otf`) or `backgrounds/` (only picture types)
/// folder. Skipped files are logged; the import itself still succeeds.
fn prune_theme_assets(root: &Path) {
    prune_dir(&root.join("fonts"), |p| {
        p.extension()
            .and_then(|e| e.to_str())
            .is_some_and(|e| e.eq_ignore_ascii_case("ttf") || e.eq_ignore_ascii_case("otf"))
    });
    prune_dir(&root.join("backgrounds"), opusdm_ipc::desktop::is_background_image);
}

/// Delete the files directly inside `dir` that `keep` rejects. A missing
/// folder is fine.
fn prune_dir(dir: &Path, keep: impl Fn(&Path) -> bool) {
    let Ok(entries) = std::fs::read_dir(dir) else { return };
    for entry in entries.flatten() {
        let path = entry.path();
        if !path.is_file() || keep(&path) {
            continue;
        }
        opusdm_ipc::err_log!("theme-config", "import: dropping unexpected file {}", path.display());
        if let Err(e) = std::fs::remove_file(&path) {
            opusdm_ipc::err_log!("theme-config", "cannot remove {}: {e}", path.display());
        }
    }
}
```

```rust
//! The Theme Editor's data side: loading an installed theme into a
//! `ThemeDraft`, creating / duplicating / deleting themes, and the pure
//! bookkeeping of pending asset operations. No GTK.

use crate::builder::slugify;
use crate::writer::{write_theme, AssetOp, BuildError, ThemeDraft};
use opusdm_ipc::desktop::Background;
use opusdm_ipc::look::{SurfaceImage, ThemeSurface};
use opusdm_ipc::themes::{theme_dir, CustomThemeData, ThemeManifest};
use std::path::{Path, PathBuf};

/// Load installed theme `slug` as an editable draft. Pictures are resolved to
/// absolute paths inside the theme folder. Errors name the file at fault; a
/// `theme.json` that exists but cannot be parsed is an error so the editor
/// never replaces it with an empty one.
pub fn load_draft(slug: &str) -> Result<ThemeDraft, String> {
    let dir = theme_dir(slug);
    let manifest_path = dir.join("manifest.json");
    let text = std::fs::read_to_string(&manifest_path).map_err(|e| format!("{}: {e}", manifest_path.display()))?;
    let manifest: ThemeManifest = serde_json::from_str(&text).map_err(|e| format!("manifest.json: {e}"))?;

    let theme_path = dir.join("theme.json");
    let data: CustomThemeData = match std::fs::read_to_string(&theme_path) {
        Ok(text) => serde_json::from_str(&text).map_err(|e| format!("theme.json: {e}"))?,
        Err(e) if e.kind() == std::io::ErrorKind::NotFound => CustomThemeData::default(),
        Err(e) => return Err(format!("{}: {e}", theme_path.display())),
    };

    let background = data.background.as_ref().map(|tb| {
        let mut bg = Background::default();
        crate::apply::merge_background(&mut bg, tb, slug);
        bg
    });
    let surface = |ts: Option<&ThemeSurface>| {
        ts.map(|t| {
            let mut s = SurfaceImage::default();
            crate::apply::merge_surface(&mut s, Some(t), slug);
            s
        })
    };
    let surfaces = data.surfaces.unwrap_or_default();
    Ok(ThemeDraft {
        label: manifest.label,
        author: manifest.author,
        version: manifest.version,
        colors: data.colors,
        appearance: data.appearance,
        behavior: data.behavior,
        desktop: data.desktop,
        background,
        fonts: data.fonts,
        lister: surface(surfaces.lister.as_ref()),
        requester: surface(surfaces.requester.as_ref()),
    })
}

/// The slug a new theme called `label` would get, or an error when the name
/// is unusable or a theme with that slug is installed.
fn free_slug(label: &str) -> Result<String, BuildError> {
    let slug = slugify(label).ok_or_else(|| BuildError::InvalidName(label.to_string()))?;
    if theme_dir(&slug).exists() {
        return Err(BuildError::Invalid(format!("a theme named \"{slug}\" already exists")));
    }
    Ok(slug)
}

/// Create an empty theme called `label` (it sets nothing yet). Returns its slug.
pub fn new_theme(label: &str) -> Result<String, BuildError> {
    let slug = free_slug(label)?;
    let draft = ThemeDraft { label: label.trim().to_string(), ..Default::default() };
    write_theme(&slug, &draft, None, &[])?;
    Ok(slug)
}

/// Copy installed theme `src_slug` under a new name. Returns the new slug.
pub fn duplicate_theme(src_slug: &str, label: &str) -> Result<String, BuildError> {
    let slug = free_slug(label)?;
    let mut draft = load_draft(src_slug).map_err(BuildError::Invalid)?;
    draft.label = label.trim().to_string();
    write_theme(&slug, &draft, Some(src_slug), &[])?;
    Ok(slug)
}

/// Delete an installed theme. The default theme cannot be deleted.
pub fn delete_theme(slug: &str) -> Result<(), String> {
    if slug == opusdm_ipc::theme::DEFAULT_THEME_SLUG {
        return Err("the default theme cannot be deleted".to_string());
    }
    let dir = theme_dir(slug);
    if !dir.join("manifest.json").is_file() {
        return Err(format!("theme \"{slug}\" is not installed"));
    }
    std::fs::remove_dir_all(&dir).map_err(|e| format!("{}: {e}", dir.display()))
}

/// Whether the editor has unsaved work: the widgets describe something other
/// than what was loaded, or file operations are pending.
pub fn is_dirty(saved: &ThemeDraft, now: &ThemeDraft, ops: &[AssetOp]) -> bool {
    saved != now || !ops.is_empty()
}

/// Queue the removal of font `name`; if that font was only added in this
/// session, cancel the add instead.
pub fn queue_remove_font(ops: &mut Vec<AssetOp>, name: &str) {
    let before = ops.len();
    ops.retain(|op| !matches!(op, AssetOp::AddFont(p) if p.file_name().is_some_and(|n| n == name)));
    if ops.len() == before {
        ops.push(AssetOp::RemoveFont(name.to_string()));
    }
}

/// Queue the removal of sound `name`; if that sound was only added in this
/// session, cancel the add instead.
pub fn queue_remove_sound(ops: &mut Vec<AssetOp>, name: &str) {
    let before = ops.len();
    ops.retain(|op| !matches!(op, AssetOp::AddSound(p) if p.file_name().is_some_and(|n| n == name)));
    if ops.len() == before {
        ops.push(AssetOp::RemoveSound(name.to_string()));
    }
}

/// Queue replacing icon `name` with `src`, superseding an earlier pending
/// replacement of the same icon.
pub fn queue_icon_replace(ops: &mut Vec<AssetOp>, name: &str, src: PathBuf) {
    ops.retain(|op| !matches!(op, AssetOp::ReplaceIcon { name: n, .. } if n == name));
    ops.push(AssetOp::ReplaceIcon { name: name.to_string(), src });
}

/// Names of the files directly inside `dir`, sorted. A missing or unreadable
/// folder gives an empty list.
pub fn list_names(dir: &Path) -> Vec<String> {
    let Ok(entries) = std::fs::read_dir(dir) else { return Vec::new() };
    let mut names: Vec<String> = entries
        .flatten()
        .filter(|e| e.path().is_file())
        .map(|e| e.file_name().to_string_lossy().to_string())
        .collect();
    names.sort();
    names
}
```

```rust
impl Editor {
    /// Slug of the open theme.
    fn current_slug(&self) -> Option<String> {
        self.current.borrow().as_ref().map(|c| c.slug.clone())
    }

    /// Rebuild the theme list and select `select` (the first row when `None`).
    fn refresh_list(&self, select: Option<&str>) {
        self.programmatic.set(true);
        while let Some(child) = self.list.first_child() {
            self.list.remove(&child);
        }
        let mut slugs = Vec::new();
        for theme in opusdm_ipc::themes::scan_themes() {
            let label = gtk::Label::builder().label(&theme.label).xalign(0.0).margin_start(6).margin_end(6).margin_top(4).margin_bottom(4).build();
            self.list.append(&label);
            slugs.push(theme.slug);
        }
        let index = select.and_then(|s| slugs.iter().position(|x| x == s)).unwrap_or(0);
        *self.slugs.borrow_mut() = slugs;
        if let Some(row) = self.list.row_at_index(index as i32) {
            self.list.select_row(Some(&row));
        }
        self.programmatic.set(false);
    }

    /// Open theme `slug`: load its draft from disk and rebuild the tabs.
    fn load(self: &Rc<Self>, slug: &str) {
        let draft = match draft::load_draft(slug) {
            Ok(d) => d,
            Err(e) => {
                self.status.set_text(&format!("Cannot open \"{slug}\": {e}"));
                return;
            }
        };
        let tabs = Tabs::new(&self.window, &draft);
        while let Some(child) = self.right.first_child() {
            self.right.remove(&child);
        }
        self.right.append(&tabs.notebook);
        *self.current.borrow_mut() = Some(Current { slug: slug.to_string(), saved: draft, ops: Rc::new(RefCell::new(Vec::new())), tabs });
    }

    /// Whether the open theme has unsaved changes.
    fn is_dirty(&self) -> bool {
        let current = self.current.borrow();
        let Some(c) = current.as_ref() else { return false };
        draft::is_dirty(&c.saved, &c.tabs.collect(&c.saved), &c.ops.borrow())
    }

    /// Run `proceed` now when nothing is unsaved, otherwise after the user
    /// agrees to discard; `cancel` runs when they decline.
    fn confirm_discard(self: &Rc<Self>, proceed: impl Fn() + 'static, cancel: impl Fn() + 'static) {
        if !self.is_dirty() {
            proceed();
            return;
        }
        opusdm_ui::requester(
            &self.window,
            "Unsaved Changes",
            "This theme has unsaved changes. Discard them?",
            None,
            &[("Discard", true), ("Cancel", false)],
            move |discard| {
                if discard {
                    proceed();
                } else {
                    cancel();
                }
            },
        );
    }

    /// The open theme's slug, the draft the widgets describe, and the pending
    /// operations. `None` when no theme is open.
    fn snapshot(&self) -> Option<(String, ThemeDraft, Vec<AssetOp>)> {
        let current = self.current.borrow();
        let c = current.as_ref()?;
        Some((c.slug.clone(), c.tabs.collect(&c.saved), c.ops.borrow().clone()))
    }

    /// Save the open theme in place; with `apply`, also apply it to the
    /// running desktop (the editor's preview).
    fn save(self: &Rc<Self>, apply: bool) {
        let Some((slug, draft, ops)) = self.snapshot() else { return };
        if let Err(e) = write_theme(&slug, &draft, Some(&slug), &ops) {
            self.status.set_text(&format!("Save failed: {e}"));
            return;
        }
        self.load(&slug);
        (self.on_saved)(slug.clone());
        let message = if apply { apply_theme(&slug) } else { "Saved.".to_string() };
        self.status.set_text(&message);
    }

    /// Save the widgets' state plus pending operations as a new theme and open it.
    fn save_as_copy(self: &Rc<Self>) {
        let Some((source, draft, ops)) = self.snapshot() else { return };
        let editor = self.clone();
        opusdm_ui::requester_entry(
            &self.window,
            "Save as Copy",
            &format!("{} copy", draft.label.trim()),
            &[("Save", true), ("Cancel", false)],
            move |save, label| {
                if !save {
                    return;
                }
                let Some(slug) = crate::builder::slugify(&label) else {
                    editor.status.set_text("The name needs at least one letter or digit.");
                    return;
                };
                if opusdm_ipc::themes::theme_dir(&slug).exists() {
                    editor.status.set_text(&format!("A theme named \"{slug}\" already exists."));
                    return;
                }
                let mut copy = draft.clone();
                copy.label = label.trim().to_string();
                match write_theme(&slug, &copy, Some(&source), &ops) {
                    Ok(_) => {
                        editor.refresh_list(Some(&slug));
                        editor.load(&slug);
                        (editor.on_saved)(slug);
                        editor.status.set_text("Saved as a copy.");
                    }
                    Err(e) => editor.status.set_text(&format!("Save failed: {e}")),
                }
            },
        );
    }

    /// Ask for a name and create an empty theme.
    fn prompt_new(self: &Rc<Self>) {
        let editor = self.clone();
        opusdm_ui::requester_entry(&self.window, "New Theme", "", &[("Create", true), ("Cancel", false)], move |create, label| {
            if !create {
                return;
            }
            match draft::new_theme(&label) {
                Ok(slug) => editor.opened(slug, "Created."),
                Err(e) => editor.status.set_text(&format!("Cannot create: {e}")),
            }
        });
    }

    /// Ask for a name and duplicate the open theme as saved on disk.
    fn prompt_duplicate(self: &Rc<Self>) {
        let Some(source) = self.current_slug() else { return };
        let editor = self.clone();
        opusdm_ui::requester_entry(&self.window, "Duplicate Theme", &format!("{source} copy"), &[("Duplicate", true), ("Cancel", false)], move |go, label| {
            if !go {
                return;
            }
            match draft::duplicate_theme(&source, &label) {
                Ok(slug) => editor.opened(slug, "Duplicated."),
                Err(e) => editor.status.set_text(&format!("Cannot duplicate: {e}")),
            }
        });
    }

    /// Ask for confirmation and delete the open theme.
    fn prompt_delete(self: &Rc<Self>) {
        let Some(slug) = self.current_slug() else { return };
        let editor = self.clone();
        opusdm_ui::requester(
            &self.window,
            "Delete Theme",
            &format!("Delete theme \"{slug}\" and all its files?"),
            None,
            &[("Delete", true), ("Cancel", false)],
            move |delete| {
                if !delete {
                    return;
                }
                match draft::delete_theme(&slug) {
                    Ok(()) => {
                        editor.refresh_list(None);
                        let first = editor.slugs.borrow().first().cloned();
                        if let Some(first) = first {
                            editor.load(&first);
                        }
                        (editor.on_saved)(opusdm_ipc::theme::DEFAULT_THEME_SLUG.to_string());
                        editor.status.set_text("Deleted.");
                    }
                    Err(e) => editor.status.set_text(&format!("Cannot delete: {e}")),
                }
            },
        );
    }

    /// Select and open a theme that was just created or duplicated.
    fn opened(self: &Rc<Self>, slug: String, message: &str) {
        self.refresh_list(Some(&slug));
        self.load(&slug);
        (self.on_saved)(slug);
        self.status.set_text(message);
    }
}

/// Apply theme `slug` over the user's current settings and desktop, the same
/// way the Settings window's Apply does. Returns the status message.
fn apply_theme(slug: &str) -> String {
    let current = load_settings();
    let desktop = opusdm_desktop_config::model::load();
    let result = apply_icon_set(&IconSetId::Custom(slug.to_string()), &current, &desktop);
    match apply_full(&result.settings, &result.desktop) {
        ApplyOutcome::SentToHub => "Saved and applied to the running desktop.".to_string(),
        ApplyOutcome::WroteFile => "Saved. No hub running: effective on next login.".to_string(),
        ApplyOutcome::Failed(e) => format!("Saved, but could not apply: {e}"),
    }
}
```

```rust
//! A list of the files a theme carries (fonts, sounds) with Add and Remove.
//! Adding or removing only queues an `AssetOp`; the files change on Save.

use crate::writer::AssetOp;
use gtk4 as gtk;
use gtk::gio;
use gtk::prelude::*;
use std::cell::RefCell;
use std::path::PathBuf;
use std::rc::Rc;

/// The widget: a heading, the file names, and Add / Remove buttons.
pub struct AssetList {
    pub root: gtk::Box,
}

/// The file name shown in `row`.
fn row_name(row: &gtk::ListBoxRow) -> Option<String> {
    row.child().and_downcast::<gtk::Label>().map(|l| l.text().to_string())
}

/// Append a row showing `name`.
fn append_name(list: &gtk::ListBox, name: &str) {
    list.append(&gtk::Label::builder().label(name).xalign(0.0).margin_start(6).margin_top(3).margin_bottom(3).build());
}

impl AssetList {
    /// Build the list under `title`, showing `names`. `suffixes` are the file
    /// extensions the Add chooser offers. `add_op` builds the operation for a
    /// chosen file; `remove` queues (or cancels) the removal of a name.
    pub fn new(
        window: &gtk::ApplicationWindow,
        title: &str,
        names: Vec<String>,
        suffixes: &'static [&'static str],
        ops: Rc<RefCell<Vec<AssetOp>>>,
        add_op: fn(PathBuf) -> AssetOp,
        remove: fn(&mut Vec<AssetOp>, &str),
    ) -> Self {
        let root = gtk::Box::new(gtk::Orientation::Vertical, 6);
        let heading = gtk::Label::new(Some(title));
        heading.set_xalign(0.0);
        heading.add_css_class("heading");
        root.append(&heading);

        let list = gtk::ListBox::new();
        list.set_selection_mode(gtk::SelectionMode::Single);
        for name in &names {
            append_name(&list, name);
        }
        root.append(&gtk::ScrolledWindow::builder().child(&list).min_content_height(120).build());

        let add_btn = gtk::Button::with_label("Add...");
        let remove_btn = gtk::Button::with_label("Remove");
        let buttons = gtk::Box::new(gtk::Orientation::Horizontal, 6);
        buttons.append(&add_btn);
        buttons.append(&remove_btn);
        root.append(&buttons);

        {
            let window = window.clone();
            let list = list.clone();
            let ops = ops.clone();
            add_btn.connect_clicked(move |_| {
                let filter = gtk::FileFilter::new();
                for suffix in suffixes {
                    filter.add_suffix(suffix);
                }
                filter.set_name(Some("Supported files"));
                let filters = gio::ListStore::new::<gtk::FileFilter>();
                filters.append(&filter);
                let dialog = gtk::FileDialog::builder().title("Add File").filters(&filters).build();
                let list = list.clone();
                let ops = ops.clone();
                dialog.open(Some(&window), gio::Cancellable::NONE, move |result| {
                    let Ok(file) = result else { return };
                    let Some(path) = file.path() else { return };
                    let Some(name) = path.file_name().map(|n| n.to_string_lossy().to_string()) else { return };
                    ops.borrow_mut().push(add_op(path));
                    let mut row = list.first_child();
                    while let Some(r) = row {
                        if r.downcast_ref::<gtk::ListBoxRow>().and_then(row_name).as_deref() == Some(name.as_str()) {
                            return;
                        }
                        row = r.next_sibling();
                    }
                    append_name(&list, &name);
                });
            });
        }
        {
            let list = list.clone();
            remove_btn.connect_clicked(move |_| {
                let Some(row) = list.selected_row() else { return };
                let Some(name) = row_name(&row) else { return };
                remove(&mut ops.borrow_mut(), &name);
                list.remove(&row);
            });
        }
        Self { root }
    }
}
```

```rust
            grid.attach(&thumb, 0, row as i32, 1, 1);
            grid.attach(&label, 1, row as i32, 1, 1);
            grid.attach(&replace, 2, row as i32, 1, 1);

            let window = window.clone();
            let ops = ops.clone();
            replace.connect_clicked(move |_| {
                let filter = gtk::FileFilter::new();
                filter.add_suffix("png");
                filter.set_name(Some("PNG icons"));
                let filters = gio::ListStore::new::<gtk::FileFilter>();
                filters.append(&filter);
                let dialog = gtk::FileDialog::builder().title("Replace Icon").filters(&filters).build();
                let thumb = thumb.clone();
                let ops = ops.clone();
                dialog.open(Some(&window), gio::Cancellable::NONE, move |result| {
                    let Ok(file) = result else { return };
                    let Some(path) = file.path() else { return };
                    thumb.set_filename(Some(&path));
                    queue_icon_replace(&mut ops.borrow_mut(), name, path);
                });
            });
        }
        Self { root: gtk::ScrolledWindow::builder().child(&grid).build() }
    }
}
```
