# Full Themes (F-35) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A theme becomes a self-contained package (colours, fonts, desktop / Lister / requester background pictures, icons, a sounds container) that can be built from the current settings (Save), packed (Export) and installed (Import).

**Architecture:** Extend the existing theme folder format (`theme.json` gains `fonts` and `surfaces`; `Settings` gains the same two defaulted fields). CSS for fonts and pictures is generated by pure functions in `opusdm-ui` and appended to the stylesheets that already exist. Save builds a staging folder and swaps it in; Export zips a theme folder through one shared packer crate also used by `xtask`.

**Tech Stack:** Rust 2021, GTK4 (gtk4-rs 0.10), serde / serde_json, zip, walkdir, tempfile, fontconfig through a tiny FFI declaration.

**Spec:** `docs/superpowers/specs/2026-10-01-full-themes-design.md`

## Global Constraints

- Code, comments and docs are English. Never write the long dash character, always `-`.
- Constants are `UPPER_SNAKE_CASE`. Every function and method has a doc comment. Early returns at the top, one line when possible.
- No new tool or dependency without need: the only new crate is `crates/themepack` (shared packer).
- `theme.json` holds values and relative file names only, never absolute paths.
- A theme is a partial override: a field is applied only where the theme sets it.
- Old `settings.json` and old `theme.json` files must still load (`#[serde(default)]`).
- Sounds are a container only: `sounds/` is copied, never played.
- Run tests with `cargo test -p <crate>`. Never use `git commit --no-verify`; if a hook fails fix the cause. Do not push. No AI attribution lines in commit messages.
- Pre-existing quirk, do not touch: `TODO.md` line for F-15 contains a literal `\n`.

## Review Focus

Failure modes the spec implies but a first reading would miss; each has a test in the named task.

1. An imported `theme.json` with an image name like `../../etc/x` or `a/b.png` must not resolve outside `backgrounds/` (Task 1: `is_plain_file_name`).
2. A font family or image path containing `"`, `\`, `;`, `}` or a newline must not break out of the generated CSS (Task 2: `css_quote`, `file_url` tests).
3. Saving a theme over the slug it was built from must not lose icons / fonts / sounds (Task 5, staging then swap).
4. A failed Save leaves neither a half-written theme nor a stray staging folder (Task 5).
5. A missing or relative background image must not produce a CSS rule or a crash; a Lister picture must not hide the file text (rows become semi-transparent) (Tasks 2 and 3).

```rust
//! CSS for a theme's fonts and background pictures. Pure string building, no
//! GTK, so every rule is unit-testable. Values coming from a theme (font
//! names, image paths) are escaped here and never spliced in raw.

use opusdm_ipc::desktop::ImageFit;
use opusdm_ipc::look::{FontSpec, SurfaceImage};
use opusdm_ipc::Settings;
use std::path::Path;

/// CSS class carried by every requester / dialog window, so a theme picture
/// can target them (and only them).
pub const REQUESTER_CLASS: &str = "opus-requester";

/// Opacity of the file rows when the Lister has a background picture, so the
/// picture shows through without hiding the text.
pub const ROW_ALPHA_WITH_PICTURE: f32 = 0.6;

/// Largest font size a theme may request, in points.
const MAX_FONT_SIZE: u32 = 72;

/// Quote `s` as a CSS string: backslash and double quote are escaped and
/// control characters (newlines included) are dropped.
fn css_quote(s: &str) -> String {
    let mut out = String::from("\"");
    for c in s.chars() {
        match c {
            '"' | '\\' => {
                out.push('\\');
                out.push(c);
            }
            c if c.is_control() => {}
            c => out.push(c),
        }
    }
    out.push('"');
    out
}

/// A CSS `url()` for an absolute file path, percent-encoding every byte that
/// is not alphanumeric or one of `/ - _ . ~`.
fn file_url(path: &Path) -> String {
    let mut out = String::from("url(\"file://");
    for b in path.to_string_lossy().bytes() {
        if b.is_ascii_alphanumeric() || b"/-_.~".contains(&b) {
            out.push(b as char);
        } else {
            out.push_str(&format!("%{b:02X}"));
        }
    }
    out.push_str("\")");
    out
}

/// The `background-*` declarations that realise `fit`.
fn fit_declarations(fit: ImageFit) -> &'static str {
    match fit {
        ImageFit::Fill => "background-repeat: no-repeat; background-position: center; background-size: cover;",
        ImageFit::Fit => "background-repeat: no-repeat; background-position: center; background-size: contain;",
        ImageFit::Center => "background-repeat: no-repeat; background-position: center; background-size: auto;",
        ImageFit::Tile => "background-repeat: repeat; background-position: top left; background-size: auto;",
    }
}

/// A rule setting the font family and size of `selector`, or an empty string
/// when `font` sets neither.
pub fn font_rule(selector: &str, font: &FontSpec) -> String {
    let mut decls = String::new();
    let family = font.family.trim();
    if !family.is_empty() {
        decls.push_str(&format!("font-family: {}; ", css_quote(family)));
    }
    if font.size > 0 {
        decls.push_str(&format!("font-size: {}pt; ", font.size.min(MAX_FONT_SIZE)));
    }
    if decls.is_empty() {
        return String::new();
    }
    format!("{selector} {{ {decls}}} ")
}

/// A rule painting `surface`'s picture on `selector`, or an empty string when
/// there is no picture, its path is not absolute, or the file is missing (the
/// last case is logged).
pub fn surface_rule(selector: &str, surface: &SurfaceImage) -> String {
    let Some(path) = surface.image_path.as_ref() else { return String::new() };
    if !path.is_absolute() {
        return String::new();
    }
    if !path.is_file() {
        opusdm_ipc::err_log!("ui", "background picture not found: {}", path.display());
        return String::new();
    }

//! Runtime registration of the font files shipped inside a theme, for the
//! current process only (nothing is installed system-wide). Uses fontconfig
//! directly because gtk4-rs does not expose it; pango, already linked by GTK,
//! sits on top of the same fontconfig.

use std::collections::HashSet;
use std::ffi::{c_char, c_int, c_void, CString};
use std::path::{Path, PathBuf};
use std::sync::Mutex;

#[link(name = "fontconfig")]
extern "C" {
    fn FcConfigAppFontAddFile(config: *mut c_void, file: *const c_char) -> c_int;
}

#[link(name = "pangocairo-1.0")]
extern "C" {
    fn pango_cairo_font_map_get_default() -> *mut c_void;
}

#[link(name = "pangoft2-1.0")]
extern "C" {
    fn pango_fc_font_map_config_changed(fontmap: *mut c_void);
}

/// Font files registered so far in this process, so a repaint does not add
/// the same file twice.
static REGISTERED: Mutex<Option<HashSet<PathBuf>>> = Mutex::new(None);

/// The `.ttf` / `.otf` files directly inside `dir`, sorted by name. A missing
/// or unreadable folder yields an empty list.
pub fn font_files(dir: &Path) -> Vec<PathBuf> {
    let Ok(entries) = std::fs::read_dir(dir) else { return Vec::new() };
    let mut files: Vec<PathBuf> = entries
        .flatten()
        .map(|e| e.path())
        .filter(|p| p.is_file())
        .filter(|p| {
            p.extension()
                .and_then(|e| e.to_str())
                .is_some_and(|e| e.eq_ignore_ascii_case("ttf") || e.eq_ignore_ascii_case("otf"))
        })
        .collect();
    files.sort();
    files
}

/// Hand one file to the default fontconfig configuration. True when
/// fontconfig accepted it.
fn register_font_file(path: &Path) -> bool {
    let Ok(c_path) = CString::new(path.to_string_lossy().as_bytes()) else { return false };
    // SAFETY: `c_path` is a valid NUL-terminated string that outlives the
    // call; a null config means "the current configuration".
    unsafe { FcConfigAppFontAddFile(std::ptr::null_mut(), c_path.as_ptr().cast()) != 0 }
}

/// Register every font file of theme `slug` (its `fonts/` folder) with this
/// process and tell pango to re-read the configuration. Returns how many
/// files were newly registered; unreadable files are logged and skipped.
pub fn register_theme_fonts(slug: &str) -> usize {
    let dir = opusdm_ipc::themes::theme_dir(slug).join("fonts");
    let mut guard = REGISTERED.lock().expect("font registry lock poisoned");
    let seen = guard.get_or_insert_with(HashSet::new);
    let mut added = 0;
    for file in font_files(&dir) {
        if seen.contains(&file) {
            continue;
        }
        if register_font_file(&file) {
            seen.insert(file);
            added += 1;
        } else {
            opusdm_ipc::err_log!("ui", "cannot register font file {}", file.display());
        }
    }
    if added > 0 {
        // SAFETY: the default pangocairo font map is a fontconfig map on
        // Linux; a null map is skipped.
        unsafe {
            let map = pango_cairo_font_map_get_default();
            if !map.is_null() {
                pango_fc_font_map_config_changed(map);
            }
        }
    }
    added
}
```

```rust
use std::fs::File;
use std::io::{self, Write};
use std::path::Path;

/// Zip the contents of `src` into `zip_path`. Entries use `/` separators and
/// are sorted by name, so the same folder always yields the same archive
/// layout. The folder itself is not an entry: `manifest.json` ends up at the
/// archive root, as the importer expects.
pub fn pack_theme_dir(src: &Path, zip_path: &Path) -> io::Result<()> {
    if !src.is_dir() {
        return Err(io::Error::new(io::ErrorKind::NotFound, format!("{} is not a folder", src.display())));
    }
    let mut zip = zip::ZipWriter::new(File::create(zip_path)?);
    let options = zip::write::SimpleFileOptions::default();
    for entry in walkdir::WalkDir::new(src).sort_by_file_name() {
        let entry = entry.map_err(io::Error::other)?;
        let rel = entry.path().strip_prefix(src).map_err(io::Error::other)?;
        if rel.as_os_str().is_empty() {
            continue;
        }
        let name = rel.to_string_lossy().replace('\\', "/");
        if entry.file_type().is_dir() {
            zip.add_directory(format!("{name}/"), options).map_err(io::Error::other)?;
        } else {
            zip.start_file(name, options).map_err(io::Error::other)?;
            zip.write_all(&std::fs::read(entry.path())?)?;
        }
    }
    zip.finish().map_err(io::Error::other)?;
    Ok(())
}
```

/// `manifest.json` `version` written by Save.
const THEME_VERSION: &str = "1";

/// Everything Save needs.
pub struct BuildRequest<'a> {
    /// Display name.
    pub label: &'a str,
    /// Folder name and `manifest.json` `name`; must pass `valid_slug`.
    pub slug: &'a str,
    /// Installed theme whose `icons/`, `fonts/` and `sounds/` are carried along.
    pub source_slug: &'a str,
    pub settings: &'a Settings,
    pub desktop: &'a DesktopSettings,
}

/// Why a Save failed.
#[derive(Debug)]
pub enum BuildError {
    InvalidName(String),
    Io { path: PathBuf, source: std::io::Error },
    Json(serde_json::Error),
}

impl fmt::Display for BuildError {
    fn fmt(&self, f: &mut fmt::Formatter<'_>) -> fmt::Result {
        match self {
            BuildError::InvalidName(n) => write!(f, "invalid theme name: {n:?}"),
            BuildError::Io { path, source } => write!(f, "{}: {source}", path.display()),
            BuildError::Json(e) => write!(f, "cannot write theme.json: {e}"),
        }
    }
}

/// Attach `path` to an I/O error.
fn io_err(path: &Path) -> impl FnOnce(std::io::Error) -> BuildError + '_ {
    move |source| BuildError::Io { path: path.to_path_buf(), source }
}

/// Turn a display name into a theme slug: lower-case ASCII letters and
/// digits, runs of anything else collapsed to a single `-`. `None` when
/// nothing usable is left.
pub fn slugify(label: &str) -> Option<String> {
    let mut slug = String::new();
    for c in label.trim().to_lowercase().chars() {
        if c.is_ascii_alphanumeric() {
            slug.push(c);
        } else if !slug.is_empty() && !slug.ends_with('-') {
            slug.push('-');
        }
    }
    let slug = slug.trim_end_matches('-').to_string();
    valid_slug(&slug).then_some(slug)
}

/// Build the theme described by `req` and install it, replacing any theme
/// with the same slug. Returns the installed folder.
pub fn save_theme(req: &BuildRequest) -> Result<PathBuf, BuildError> {
    if !valid_slug(req.slug) || req.label.trim().is_empty() {
        return Err(BuildError::InvalidName(req.slug.to_string()));
    }
    let root = themes_dir();
    std::fs::create_dir_all(&root).map_err(io_err(&root))?;
    let staging = root.join(format!(".{}.tmp", req.slug));
    if staging.exists() {
        std::fs::remove_dir_all(&staging).map_err(io_err(&staging))?;
    }
    if let Err(e) = stage(req, &staging) {
        if let Err(clean) = std::fs::remove_dir_all(&staging) {
            opusdm_ipc::err_log!("theme-config", "cannot remove {}: {clean}", staging.display());
        }
        return Err(e);
    }
    let dest = theme_dir(req.slug);
    if dest.exists() {
        std::fs::remove_dir_all(&dest).map_err(io_err(&dest))?;
    }
    std::fs::rename(&staging, &dest).map_err(io_err(&dest))?;
    Ok(dest)
}

/// Write the whole theme into `dir`.
fn stage(req: &BuildRequest, dir: &Path) -> Result<(), BuildError> {
    let backgrounds = dir.join("backgrounds");
    let s = req.settings;
    let data = CustomThemeData {
        colors: Some(s.theme.colors.clone()),
        appearance: Some(s.appearance.clone()),
        behavior: Some(s.behavior.clone()),
        desktop: Some(ThemeDesktopMetrics {
            icon_size: Some(req.desktop.icon_size),
            grid_spacing: Some(req.desktop.grid_spacing),
            grid_gap: Some(req.desktop.grid_gap),
        }),
        background: Some(theme_background(&s.theme.background, &backgrounds)?),
        fonts: Some(s.fonts.clone()),
        surfaces: Some(ThemeSurfaces {
            lister: Some(theme_surface(&s.surfaces.lister, &backgrounds, "lister")?),
            requester: Some(theme_surface(&s.surfaces.requester, &backgrounds, "requester")?),
        }),
    };
    let source = theme_dir(req.source_slug);
    for part in ["icons", "fonts", "sounds"] {
        copy_dir_if_exists(&source.join(part), &dir.join(part))?;
    }
    let manifest = ThemeManifest {
        name: req.slug.to_string(),
        label: req.label.trim().to_string(),
        author: None,
        version: Some(THEME_VERSION.to_string()),
    };
    write_json(&dir.join("manifest.json"), &manifest)?;
    write_json(&dir.join("theme.json"), &data)
}

/// Serialize `value` to `path` as pretty JSON.
fn write_json<T: serde::Serialize>(path: &Path, value: &T) -> Result<(), BuildError> {
    let text = serde_json::to_string_pretty(value).map_err(BuildError::Json)?;
    std::fs::write(path, text + "\n").map_err(io_err(path))
}

/// The desktop background as a theme section. A picture is only carried when
/// the mode actually uses it: the path is kept in other modes so switching
/// back is lossless, but it may be stale.
fn theme_background(bg: &Background, backgrounds: &Path) -> Result<ThemeBackground, BuildError> {
    let image = match (bg.mode, &bg.image_path) {
        (BackgroundMode::Image, Some(p)) => Some(copy_picture(p, backgrounds, "desktop")?),
        _ => None,
    };
    Ok(ThemeBackground {
        mode: Some(bg.mode),
        solid: Some(bg.solid.clone()),
        gradient_start: Some(bg.gradient_start.clone()),
        gradient_end: Some(bg.gradient_end.clone()),
        gradient_angle: Some(bg.gradient_angle),
        image,
        image_fit: Some(bg.image_fit),
    })
}

/// One surface as a theme section, copying its picture (named `stem.<ext>`).
fn theme_surface(surface: &SurfaceImage, backgrounds: &Path, stem: &str) -> Result<ThemeSurface, BuildError> {
    let image = surface.image_path.as_ref().map(|p| copy_picture(p, backgrounds, stem)).transpose()?;
    Ok(ThemeSurface { image, fit: Some(surface.fit) })
}

/// Copy `src` into `backgrounds/` as `<stem>.<original extension>` and
/// return that file name.
fn copy_picture(src: &Path, backgrounds: &Path, stem: &str) -> Result<String, BuildError> {
    let ext = src.extension().and_then(|e| e.to_str()).unwrap_or("png").to_ascii_lowercase();
    let name = format!("{stem}.{ext}");
    std::fs::create_dir_all(backgrounds).map_err(io_err(backgrounds))?;
    std::fs::copy(src, backgrounds.join(&name)).map_err(io_err(src))?;
    Ok(name)
}

/// Recursively copy `src` to `dst`; a missing `src` is not an error.
fn copy_dir_if_exists(src: &Path, dst: &Path) -> Result<(), BuildError> {
    if !src.is_dir() {
        return Ok(());
    }
    std::fs::create_dir_all(dst).map_err(io_err(dst))?;
    for entry in std::fs::read_dir(src).map_err(io_err(src))? {
        let entry = entry.map_err(io_err(src))?;
        let to = dst.join(entry.file_name());
        if entry.path().is_dir() {
            copy_dir_if_exists(&entry.path(), &to)?;
        } else {
            std::fs::copy(entry.path(), &to).map_err(io_err(&entry.path()))?;
        }
    }
    Ok(())
}

/// Remove from the staged theme every file that has no business in its
/// `fonts/` (only `.ttf` / `.otf`) or `backgrounds/` (only picture types)
/// folder. Skipped files are logged; the import itself still succeeds.
fn prune_theme_assets(root: &Path) {
    prune_dir(&root.join("fonts"), |p| {
        p.extension()
            .and_then(|e| e.to_str())
            .is_some_and(|e| e.eq_ignore_ascii_case("ttf") || e.eq_ignore_ascii_case("otf"))
    });
    prune_dir(&root.join("backgrounds"), opusdm_ipc::desktop::is_background_image);
}

/// Delete the files directly inside `dir` that `keep` rejects. A missing
/// folder is fine.
fn prune_dir(dir: &Path, keep: impl Fn(&Path) -> bool) {
    let Ok(entries) = std::fs::read_dir(dir) else { return };
    for entry in entries.flatten() {
        let path = entry.path();
        if !path.is_file() || keep(&path) {
            continue;
        }
        opusdm_ipc::err_log!("theme-config", "import: dropping unexpected file {}", path.display());
        if let Err(e) = std::fs::remove_file(&path) {
            opusdm_ipc::err_log!("theme-config", "cannot remove {}: {e}", path.display());
        }
    }
}
