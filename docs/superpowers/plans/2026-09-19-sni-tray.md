# OpusDM Panel SNI tray Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add StatusNotifierItem/DBus tray support to `opusdm-panel`, alongside the existing XEmbed tray, so apps that only speak SNI (e.g. modern `nm-applet`) show up too - with their real DBusMenu, since most SNI apps (`ItemIsMenu=true`) are inert without it.

**Architecture:** A background thread in a new `crates/panel/src/sni.rs` owns a `zbus::blocking::Connection` to the session bus and either runs `org.kde.StatusNotifierWatcher` itself (the common case - nothing else provides one on this WM) or, if that name is already taken, connects as a plain client to whatever host does. A new `crates/panel/src/dbusmenu.rs` is a `com.canonical.dbusmenu` client: fetches an app's menu tree and renders it as a `gtk::PopoverMenu`. A new `crates/panel/src/widgets/sni.rs` shows one clickable icon per hosted item next to the existing XEmbed tray widget.

**Tech Stack:** Rust, gtk4, zbus 5 (blocking feature), gdk-pixbuf (already pulled in by gtk4), std::sync::mpsc, async-channel.

**Spec:** `docs/superpowers/specs/2026-09-19-sni-tray-design.md`

## Global Constraints

- `zbus::blocking` only - no async runtime dependency beyond what zbus
  pulls in internally; the thread's own code reads synchronously, matching
  `ewmh.rs`/`systray.rs`.
- No toggle/radio/checkmark rendering in the DBusMenu popover - plain
  clickable rows only (spec's v1 cut).
- No `Status`/tooltip visual handling - every item renders the same way.
- If `org.kde.StatusNotifierWatcher` is already owned by another process,
  never contend for it - connect as a host client to the existing one.
- No automated tests for the live DBus protocol (watcher registration,
  property fetch, signal subscriptions, menu round-trips) - only the
  DBusMenu tree parser gets unit tests, matching the XEmbed tray's
  precedent of only testing pure/parsing logic.
- zbus's exact `zvariant` helper method names may need small adjustments
  during each task's build-verification step (offline plan authoring can't
  cross-check every signature against the resolved crate version) - treat
  build errors in these tasks as expected iteration, not a blocker to stop
  on, the same way `x11rb` import paths were fixed live in the XEmbed plan.

```rust
//! StatusNotifierItem (SNI) tray: a background thread (`spawn`) either runs
//! `org.kde.StatusNotifierWatcher` itself or, if one is already running,
//! connects to it as a host - then tracks every registered item's icon,
//! title and menu path. Companion to `systray.rs` (XEmbed); together they
//! cover both tray protocols apps use in the wild.

use std::sync::mpsc;

use crate::ewmh::IconRgba;

/// The state the GTK side needs to render one hosted item's icon and know
/// whether clicking it should show a DBusMenu.
#[derive(Clone, Debug)]
pub struct SniItem {
    pub icon: Option<IconRgba>,
    pub icon_name: Option<String>,
    pub title: String,
    pub item_is_menu: bool,
    pub menu_path: Option<zbus::zvariant::OwnedObjectPath>,
}

/// Snapshots the SNI thread sends to the GTK side, keyed by the item's
/// DBus service name (unique per registered item).
#[derive(Clone, Debug)]
pub enum SniEvent {
    ItemAdded { service: String, item: SniItem },
    ItemChanged { service: String, item: SniItem },
    ItemRemoved { service: String },
}

/// Commands the GTK side sends to the SNI thread.
#[derive(Clone, Debug)]
pub enum SniCmd {
    Activate { service: String, x: i32, y: i32 },
    ContextMenu { service: String, x: i32, y: i32 },
}

/// Start the SNI thread. Returns a command sender and event receiver; if no
/// session bus is available, the thread logs once and exits - the channels
/// stay open but nothing is ever sent or received. Mirrors `systray::spawn`.
pub fn spawn() -> (mpsc::Sender<SniCmd>, async_channel::Receiver<SniEvent>) {
    let (cmd_tx, cmd_rx) = mpsc::channel::<SniCmd>();
    let (evt_tx, evt_rx) = async_channel::unbounded::<SniEvent>();
    std::thread::Builder::new()
        .name("opusdm-panel-sni".into())
        .spawn(move || {
            if let Err(e) = run(cmd_rx, evt_tx) {
                eprintln!("opusdm-panel: SNI tray stopped: {e}");
            }
        })
        .expect("spawn sni thread");
    (cmd_tx, evt_rx)
}

fn run(
    _cmd_rx: mpsc::Receiver<SniCmd>,
    _tx: async_channel::Sender<SniEvent>,
) -> Result<(), Box<dyn std::error::Error>> {
    let _conn = zbus::blocking::Connection::session()?;
    // Watcher registration and the event loop land in Task 2-3.
    Ok(())
}
```

```rust
use std::collections::HashMap;
use std::sync::{Arc, Mutex};

/// Shared registry the watcher interface mutates and the event loop reads.
/// `Mutex` (not `RefCell`) because zbus's interface methods run on its own
/// internal executor thread, separate from this module's own loop below.
#[derive(Default)]
struct WatcherState {
    items: Vec<String>, // registered service names
}

struct Watcher {
    state: Arc<Mutex<WatcherState>>,
    tx: async_channel::Sender<SniEvent>,
}

#[zbus::interface(name = "org.kde.StatusNotifierWatcher")]
impl Watcher {
    async fn register_status_notifier_item(&self, service: &str) {
        let already = {
            let mut s = self.state.lock().unwrap();
            if s.items.iter().any(|i| i == service) {
                true
            } else {
                s.items.push(service.to_string());
                false
            }
        };
        if already {
            return;
        }
        if let Ok(item) = fetch_item(service) {
            let _ = self.tx.send_blocking(SniEvent::ItemAdded { service: service.to_string(), item });
        }
    }

    async fn register_status_notifier_host(&self, _service: &str) {
        // Accepted for spec completeness; see the design doc's note on
        // `IsStatusNotifierHostRegistered`.
    }

    #[zbus(property)]
    async fn registered_status_notifier_items(&self) -> Vec<String> {
        self.state.lock().unwrap().items.clone()
    }

    #[zbus(property)]
    async fn is_status_notifier_host_registered(&self) -> bool {
        true
    }

    #[zbus(property)]
    async fn protocol_version(&self) -> i32 {
        0
    }
}
```

- [ ] **Step 2: `fetch_item` - read one item's properties over DBus**

```rust
/// Build a blocking proxy to `service`'s `org.kde.StatusNotifierItem`
/// interface and read the properties the widget needs. A fresh short-lived
/// connection per call, same throwaway style as `ewmh.rs`'s click actions -
/// this only runs once per (un)registration, not per frame.
fn fetch_item(service: &str) -> Result<SniItem, Box<dyn std::error::Error>> {
    let conn = zbus::blocking::Connection::session()?;
    let proxy = zbus::blocking::Proxy::new(&conn, service, "/StatusNotifierItem", "org.kde.StatusNotifierItem")?;

    let title: String = proxy.get_property("Title").unwrap_or_default();
    let item_is_menu: bool = proxy.get_property("ItemIsMenu").unwrap_or(false);
    let icon_name: Option<String> = proxy.get_property::<String>("IconName").ok().filter(|s| !s.is_empty());
    let menu_path: Option<zbus::zvariant::OwnedObjectPath> = proxy.get_property("Menu").ok();

    // IconPixmap: array of (i32 width, i32 height, Vec<u8> ARGB32 rows),
    // same wire shape `ewmh::pick_icon` already unpacks for _NET_WM_ICON,
    // but SNI hands it over pre-split per-icon rather than as one flat
    // word stream - convert the closest (to 24px) entry directly here.
    let icon = proxy
        .get_property::<Vec<(i32, i32, Vec<u8>)>>("IconPixmap")
        .ok()
        .and_then(|pixmaps| pick_sni_icon(&pixmaps, 24));

    Ok(SniItem { icon, icon_name, title, item_is_menu, menu_path })
}

/// Pick the pixmap closest to `target` px and unpack its big-endian ARGB32
/// bytes into tightly packed RGBA8 - mirrors `ewmh::pick_icon`'s pixel
/// unpacking, adapted to SNI's already-split-by-icon wire shape.
fn pick_sni_icon(pixmaps: &[(i32, i32, Vec<u8>)], target: i32) -> Option<IconRgba> {
    let (w, h, bytes) = pixmaps.iter().min_by_key(|(w, _, _)| (*w - target).abs())?;
    let mut rgba = Vec::with_capacity(bytes.len());
    for px in bytes.chunks_exact(4) {
        let (a, r, g, b) = (px[0], px[1], px[2], px[3]);
        rgba.extend_from_slice(&[r, g, b, a]);
    }
    Some(IconRgba { width: *w, height: *h, rgba })
}
```

- [ ] **Step 3: Wire watcher startup into `run`**

Replace `run`'s body from Task 1:

```rust
fn run(
    cmd_rx: mpsc::Receiver<SniCmd>,
    tx: async_channel::Sender<SniEvent>,
) -> Result<(), Box<dyn std::error::Error>> {
    let state = Arc::new(Mutex::new(WatcherState::default()));
    let watcher = Watcher { state: state.clone(), tx: tx.clone() };

    let conn = zbus::blocking::connection::Builder::session()?
        .name("org.kde.StatusNotifierWatcher")
        .and_then(|b| b.serve_at("/StatusNotifierWatcher", watcher))
        .and_then(|b| b.build());

    let conn = match conn {
        Ok(conn) => conn,
        Err(_) => {
            eprintln!("opusdm-panel: SNI watcher already running, connecting as host only");
            return run_as_host_client(cmd_rx, tx);
        }
    };

    event_loop(&conn, &state, &cmd_rx, &tx)
}

/// Fallback when another process already owns the watcher name: just
/// process commands (no items to track ourselves - the design's non-goal
/// "never runs two watchers" means we don't duplicate its registry here).
fn run_as_host_client(
    cmd_rx: mpsc::Receiver<SniCmd>,
    tx: async_channel::Sender<SniEvent>,
) -> Result<(), Box<dyn std::error::Error>> {
    let conn = zbus::blocking::Connection::session()?;
    let state = Arc::new(Mutex::new(WatcherState::default()));
    event_loop(&conn, &state, &cmd_rx, &tx)
}

/// Poll interval for draining `SniCmd`s; the watcher interface itself is
/// served by zbus's own internal executor, so this loop only needs to
/// forward GTK-side commands to DBus method calls.
const POLL_INTERVAL: std::time::Duration = std::time::Duration::from_millis(50);

fn event_loop(
    conn: &zbus::blocking::Connection,
    _state: &Arc<Mutex<WatcherState>>,
    cmd_rx: &mpsc::Receiver<SniCmd>,
    _tx: &async_channel::Sender<SniEvent>,
) -> Result<(), Box<dyn std::error::Error>> {
    loop {
        match cmd_rx.recv_timeout(POLL_INTERVAL) {
            Ok(SniCmd::Activate { service, x, y }) => send_activate(conn, &service, x, y),
            Ok(SniCmd::ContextMenu { service, x, y }) => send_context_menu(conn, &service, x, y),
            Err(mpsc::RecvTimeoutError::Timeout) => {}
            Err(mpsc::RecvTimeoutError::Disconnected) => return Ok(()),
        }
    }
}

fn send_activate(conn: &zbus::blocking::Connection, service: &str, x: i32, y: i32) {
    let run = || -> Result<(), Box<dyn std::error::Error>> {
        let proxy = zbus::blocking::Proxy::new(conn, service, "/StatusNotifierItem", "org.kde.StatusNotifierItem")?;
        proxy.call_method("Activate", &(x, y))?;
        Ok(())
    };
    if let Err(e) = run() {
        eprintln!("opusdm-panel: SNI Activate failed for {service}: {e}");
    }
}

fn send_context_menu(conn: &zbus::blocking::Connection, service: &str, x: i32, y: i32) {
    let run = || -> Result<(), Box<dyn std::error::Error>> {
        let proxy = zbus::blocking::Proxy::new(conn, service, "/StatusNotifierItem", "org.kde.StatusNotifierItem")?;
        proxy.call_method("ContextMenu", &(x, y))?;
        Ok(())
    };
    if let Err(e) = run() {
        eprintln!("opusdm-panel: SNI ContextMenu failed for {service}: {e}");
    }
}
```

- [ ] **Step 1: Watch each item's `NameOwnerChanged` and `PropertiesChanged`**

Add to `crates/panel/src/sni.rs`, and call it from

blocking signal-receive loop):

```rust
/// Watch one item's DBus name for loss (app exit) and its properties for
/// changes, for as long as the item stays registered. Runs on its own
/// thread since each needs an independent blocking signal stream; sends
/// `ItemChanged`/`ItemRemoved` back through `tx`.
fn watch_item(service: String, tx: async_channel::Sender<SniEvent>) {
    std::thread::spawn(move || {
        let Ok(conn) = zbus::blocking::Connection::session() else { return };
        let Ok(dbus_proxy) = zbus::blocking::fdo::DBusProxy::new(&conn) else { return };
        let Ok(mut owner_changes) = dbus_proxy.receive_name_owner_changed() else { return };

        let Ok(props_proxy) = zbus::blocking::Proxy::new(
            &conn,
            service.as_str(),
            "/StatusNotifierItem",
            "org.freedesktop.DBus.Properties",
        ) else {
            return;
        };
        let Ok(mut changes) = props_proxy.receive_signal("PropertiesChanged") else { return };

        loop {
            // Either signal stream waking up means "re-check this item":
            // a real removal will fail `fetch_item` on the next iteration
            // once the name is fully gone, which is simpler than parsing
            // the NameOwnerChanged/PropertiesChanged payloads themselves.
            if owner_changes.next().is_none() && changes.next().is_none() {
                break;
            }
            match fetch_item(&service) {
                Ok(item) => {
                    let _ = tx.send_blocking(SniEvent::ItemChanged { service: service.clone(), item });
                }
                Err(_) => {
                    let _ = tx.send_blocking(SniEvent::ItemRemoved { service: service.clone() });
                    break;
                }
            }
        }
    });
}
```

```rust
//! `com.canonical.dbusmenu` client: fetches an SNI item's menu tree and
//! renders it as a `gtk::PopoverMenu`. Companion to `sni.rs` - most SNI
//! apps set `ItemIsMenu=true` and rely on the host (us) to show this menu
//! rather than reacting to a plain click.

use std::collections::HashMap;
use zbus::zvariant::OwnedValue;

#[derive(Clone, Debug, PartialEq)]
pub struct MenuNode {
    pub id: i32,
    pub label: String,
    pub enabled: bool,
    pub visible: bool,
    pub is_separator: bool,
    pub children: Vec<MenuNode>,
}

/// Build one `MenuNode` from an already-decoded property map and
/// already-parsed children, applying the DBusMenu spec's fallback
/// defaults for absent properties (`label`="", `enabled`/`visible`=true,
/// `type`!="separator" unless explicitly set).
pub fn parse_layout_node(id: i32, props: &HashMap<String, OwnedValue>, children: Vec<MenuNode>) -> MenuNode {
    let label = props
        .get("label")
        .and_then(|v| String::try_from(v.clone()).ok())
        .unwrap_or_default();
    let enabled = props
        .get("enabled")
        .and_then(|v| bool::try_from(v.clone()).ok())
        .unwrap_or(true);
    let visible = props
        .get("visible")
        .and_then(|v| bool::try_from(v.clone()).ok())
        .unwrap_or(true);
    let is_separator = props
        .get("type")
        .and_then(|v| String::try_from(v.clone()).ok())
        .is_some_and(|t| t == "separator");
    MenuNode { id, label, enabled, visible, is_separator, children }
}
```

```rust
/// Call `AboutToShow` (many apps lazily populate their menu here, per
/// spec convention) then `GetLayout` on `service`'s dbusmenu object at
/// `path`, and parse the result into a `MenuNode` tree.
pub fn fetch_layout(
    conn: &zbus::blocking::Connection,
    service: &str,
    path: &zbus::zvariant::OwnedObjectPath,
) -> Result<MenuNode, Box<dyn std::error::Error>> {
    let proxy = zbus::blocking::Proxy::new(conn, service, path.as_str(), "com.canonical.dbusmenu")?;
    let _ = proxy.call_method("AboutToShow", &(0_i32,));

    let (_revision, layout): (u32, (i32, HashMap<String, OwnedValue>, Vec<OwnedValue>)) =
        proxy.call("GetLayout", &(0_i32, -1_i32, Vec::<String>::new()))?;

    Ok(parse_layout_tuple(layout))
}

/// Recursively turn one `(id, properties, children)` zvariant tuple (each
/// child itself wrapped in a `Variant` since the array is heterogeneous by
/// depth) into a `MenuNode` tree, via `parse_layout_node` for the leaf work.
fn parse_layout_tuple(node: (i32, HashMap<String, OwnedValue>, Vec<OwnedValue>)) -> MenuNode {
    let (id, props, raw_children) = node;
    let children = raw_children
        .into_iter()
        .filter_map(|v| v.try_into().ok())
        .map(parse_layout_tuple)
        .collect();
    parse_layout_node(id, &props, children)
}

/// Send a `clicked` event for `id` back to `service`'s dbusmenu object -
/// call this right after the user activates a popover row.
pub fn send_event_clicked(
    conn: &zbus::blocking::Connection,
    service: &str,
    path: &zbus::zvariant::OwnedObjectPath,
    id: i32,
) {
    let run = || -> Result<(), Box<dyn std::error::Error>> {
        let proxy = zbus::blocking::Proxy::new(conn, service, path.as_str(), "com.canonical.dbusmenu")?;
        let data = zbus::zvariant::Value::from(0_i32);
        proxy.call_method("Event", &(id, "clicked", data, 0_u32))?;
        Ok(())
    };
    if let Err(e) = run() {
        eprintln!("opusdm-panel: dbusmenu Event failed for {service}: {e}");
    }
}
```

```rust
use gtk4 as gtk;
use gtk::prelude::*;

/// Build a `gtk::PopoverMenu` from `root`'s children (the root node itself
/// is never shown - it's the menu's invisible container). Each visible,
/// non-separator leaf/branch becomes one action; separators become menu
/// section breaks. Submenus nest as `gio::Menu` submenus. `on_click` fires
/// with the clicked node's dbusmenu id.
pub fn build_popover(root: &MenuNode, on_click: impl Fn(i32) + 'static) -> gtk::PopoverMenu {
    let actions = gio::SimpleActionGroup::new();
    let menu = build_gio_menu(&root.children, &actions, &std::rc::Rc::new(on_click));

    let popover = gtk::PopoverMenu::from_model(Some(&menu));
    popover.insert_action_group("dbusmenu", Some(&actions));
    popover
}

fn build_gio_menu(
    nodes: &[MenuNode],
    actions: &gio::SimpleActionGroup,
    on_click: &std::rc::Rc<impl Fn(i32) + 'static>,
) -> gio::Menu {
    let menu = gio::Menu::new();
    let mut section = gio::Menu::new();
    for node in nodes {
        if !node.visible {
            continue;
        }
        if node.is_separator {
            if section.n_items() > 0 {
                menu.append_section(None, &section);
                section = gio::Menu::new();
            }
            continue;
        }
        let action_name = format!("item{}", node.id);
        if node.children.is_empty() {
            let action = gio::SimpleAction::new(&action_name, None);
            action.set_enabled(node.enabled);
            {
                let on_click = on_click.clone();
                let id = node.id;
                action.connect_activate(move |_, _| on_click(id));
            }
            actions.add_action(&action);
            section.append(Some(&node.label), Some(&format!("dbusmenu.{action_name}")));
        } else {
            let submenu = build_gio_menu(&node.children, actions, on_click);
            section.append_submenu(Some(&node.label), &submenu);
        }
    }
    if section.n_items() > 0 {
        menu.append_section(None, &section);
    }
    menu
}
```

```rust
//! Hosted SNI item icons: one small clickable button per item registered
//! with `sni.rs`'s watcher, rendered from the item's pixmap (or icon-theme
//! name as a fallback). Click handling (DBusMenu popover vs a plain

use gtk4 as gtk;
use gtk::prelude::*;
use std::cell::RefCell;
use std::collections::HashMap;
use std::rc::Rc;
use std::sync::mpsc::Sender;

/// Build the (initially empty) SNI icon strip and start draining `evt_rx`
/// into it. `cmd_tx` is the sender half from `sni::spawn`.
pub fn build(cmd_tx: Sender<SniCmd>, evt_rx: async_channel::Receiver<SniEvent>) -> gtk::Widget {
    let root = gtk::Box::new(gtk::Orientation::Horizontal, 4);
    root.set_valign(gtk::Align::Center);

    let buttons: Rc<RefCell<HashMap<String, gtk::Button>>> = Rc::new(RefCell::new(HashMap::new()));

    {
        let root = root.clone();
        let buttons = buttons.clone();
        glib::spawn_future_local(async move {
            while let Ok(ev) = evt_rx.recv().await {
                apply_event(&root, &buttons, &cmd_tx, ev);
            }
        });
    }

    root.upcast()
}

/// Reconcile one `SniEvent` into the displayed buttons: add/update/remove.
pub fn apply_event(
    root: &gtk::Box,
    buttons: &Rc<RefCell<HashMap<String, gtk::Button>>>,
    _cmd_tx: &Sender<SniCmd>,
    ev: SniEvent,
) {
    match ev {
        SniEvent::ItemAdded { service, item } | SniEvent::ItemChanged { service, item } => {
            let mut buttons = buttons.borrow_mut();
            if let Some(btn) = buttons.get(&service) {
                btn.set_child(Some(&icon_widget(&item)));
            } else {
                let btn = gtk::Button::new();
                btn.add_css_class("flat");
                btn.set_child(Some(&icon_widget(&item)));
                root.append(&btn);
                buttons.insert(service, btn);
            }
        }
        SniEvent::ItemRemoved { service } => {
            if let Some(btn) = buttons.borrow_mut().remove(&service) {
                root.remove(&btn);
            }
        }
    }
}

/// Render one item's icon: its pixmap when present, else an icon-theme
/// lookup by name, else a generic placeholder glyph.
fn icon_widget(item: &SniItem) -> gtk::Widget {
    if let Some(icon) = &item.icon {
        let bytes = glib::Bytes::from(&icon.rgba);
        let pixbuf = gtk::gdk_pixbuf::Pixbuf::from_bytes(
            &bytes,
            gtk::gdk_pixbuf::Colorspace::Rgb,
            true,
            8,
            icon.width,
            icon.height,
            icon.width * 4,
        );
        return gtk::Image::from_pixbuf(Some(&pixbuf)).upcast();
    }
    if let Some(name) = &item.icon_name {
        let image = gtk::Image::from_icon_name(name);
        image.set_pixel_size(18);
        return image.upcast();
    }
    let image = gtk::Image::from_icon_name("image-missing");
    image.set_pixel_size(18);
    image.upcast()
}
```

```rust
/// Attach primary/secondary click handling to one item's button: show its
/// DBusMenu popover when it has one, otherwise send `Activate`/
/// `ContextMenu` over `cmd_tx`.
fn wire_click(
    btn: &gtk::Button,
    service: String,
    menu_path: Rc<RefCell<Option<zbus::zvariant::OwnedObjectPath>>>,
    cmd_tx: Sender<SniCmd>,
) {
    let click = |button_id: u32| {
        let btn = btn.clone();
        let service = service.clone();
        let menu_path = menu_path.clone();
        let cmd_tx = cmd_tx.clone();
        move |_gesture: &gtk::GestureClick, _n: i32, x: f64, y: f64| {
            if let Some(path) = menu_path.borrow().clone() {
                show_menu(&btn, &service, &path);
                return;
            }
            let cmd = if button_id == 1 {
                SniCmd::Activate { service: service.clone(), x: x as i32, y: y as i32 }
            } else {
                SniCmd::ContextMenu { service: service.clone(), x: x as i32, y: y as i32 }
            };
            let _ = cmd_tx.send(cmd);
        }
    };

    let primary = gtk::GestureClick::new();
    primary.set_button(gtk::gdk::BUTTON_PRIMARY);
    primary.connect_pressed(click(1));
    btn.add_controller(primary);

    let secondary = gtk::GestureClick::new();
    secondary.set_button(gtk::gdk::BUTTON_SECONDARY);
    secondary.connect_pressed(click(3));
    btn.add_controller(secondary);
}

/// Fetch and show `service`'s DBusMenu, anchored to `btn`. A short-lived
/// connection + blocking call, same throwaway style as `sni.rs`'s
/// `send_activate`/`send_context_menu` - acceptable since this only runs
/// once per click, not per frame.
fn show_menu(btn: &gtk::Button, service: &str, path: &zbus::zvariant::OwnedObjectPath) {
    let Ok(conn) = zbus::blocking::Connection::session() else { return };
    let Ok(root) = crate::dbusmenu::fetch_layout(&conn, service, path) else { return };

    let service = service.to_string();
    let path = path.clone();
    let popover = crate::dbusmenu::build_popover(&root, move |id| {
        if let Ok(conn) = zbus::blocking::Connection::session() {
            crate::dbusmenu::send_event_clicked(&conn, &service, &path, id);
        }
    });
    popover.set_parent(btn);
    popover.popup();
}
```

`async_channel::Receiver` isn't `Clone`-and-reuse-safe across multiple
bars the way `mpsc::Sender` is (only one consumer should ever drain SNI
events - the primary bar's widget), so pass `Some(rx)` only for `i == 0`
and consume it there; every other bar gets `None`. Since `rebuild` may run
more than once (monitor hotplug) but `sni_evt_rx` is a single receiver
that can't be recreated, move it into an `Rc<RefCell<Option<...>>>` that
gets `.take()`n by the first (primary) bar each time `rebuild` runs:

```rust
    let sni_evt_rx = Rc::new(RefCell::new(Some(sni_evt_rx)));

    let rebuild: Rc<dyn Fn(Vec<(i32, i32, i32, i32)>)> = {
        let app = app.clone();
        let state = state.clone();
        let windows = windows.clone();
        let tray_cmd_tx = tray_cmd_tx.clone();
        let sni_cmd_tx = sni_cmd_tx.clone();
        let sni_evt_rx = sni_evt_rx.clone();
        Rc::new(move |mut rects: Vec<(i32, i32, i32, i32)>| {
            for bw in windows.borrow_mut().drain(..) {
                bw.window.close();
            }
            if rects.is_empty() {
                rects.push((0, 0, 1280, 800));
            }
            let mut rx_slot = sni_evt_rx.borrow_mut();
            let built = rects
                .into_iter()
                .enumerate()
                .map(|(i, (x, y, w, _h))| {
                    let rx = if i == 0 { rx_slot.take().flatten() } else { None };
                    build_bar_window(&app, x, y, w, &state, i == 0, tray_cmd_tx.clone(), sni_cmd_tx.clone(), rx)
                })
                .collect();
            drop(rx_slot);
            *windows.borrow_mut() = built;
        })
    };
```

its commands/events flow through `PanelState.tray_order`, not a
directly-consumed receiver). Leave a comment noting it; fixing it (route
