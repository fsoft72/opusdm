# OpusDM Panel system tray - Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a legacy XEmbed system tray to `opusdm-panel`'s right side, before the CPU/network widget, so other apps can dock a tray icon.

**Architecture:** A background thread in a new `crates/panel/src/systray.rs` owns an x11rb connection, becomes the `_NET_SYSTEM_TRAY_S<n>` selection owner, and handles dock requests by reparenting each icon window into its own small override-redirect container window, per the freedesktop `systemtray-spec` + XEmbed. A new `crates/panel/src/widgets/tray.rs` GTK widget shows one fixed-size placeholder square per docked icon (in dock order) and tells the thread where to move each icon's container via a command channel, using the same root-coordinate trick `window.rs` already uses (`mon_x`/`mon_y` + local bounds).

**Tech Stack:** Rust, gtk4, x11rb, gdk4-x11, async-channel, std::sync::mpsc (all already dependencies of `opusdm-panel`; no new crates).

**Spec:** `docs/superpowers/specs/2026-09-19-systray-design.md`

## Global Constraints

- XEmbed protocol only (no StatusNotifierItem/DBus).
- X11-only: no Wayland fallback beyond "stay silent, don't crash".
- One tray manager total (not one per monitor); tray widget only appears on
  the primary bar (index 0 of the monitor rects), matching how `opusdm-hub`
  treats index 0 as primary.
- If a system tray selection is already owned by another process, do not
  contend for it - log once and stay inactive.
- No automated tests for the live X11 protocol (selection ownership,
  reparenting, XEMBED handshake) - only the pure/parsing helpers get unit
  tests, matching the existing style in `ewmh.rs` and `window.rs`.

```rust
/// `_NET_SYSTEM_TRAY_OPCODE` opcode: a client asks to dock its icon.
pub const SYSTEM_TRAY_REQUEST_DOCK: u32 = 0;

/// `_XEMBED` opcode sent by the embedder once a client is docked.
pub const XEMBED_EMBEDDED_NOTIFY: u32 = 0;

/// Vertical/horizontal margin reserved around each docked icon inside its
/// container window, so icons don't touch the panel edge.
pub const ICON_MARGIN: i32 = 8;

/// The square size (in px) a docked icon's container window gets, derived
/// from the panel's height.
pub fn icon_square_size(panel_height: i32) -> i32 {
    (panel_height - 2 * ICON_MARGIN).max(1)
}

/// Data words for the root `MANAGER` `ClientMessage` announcing that the
/// tray selection now has an owner.
pub fn manager_message_data(timestamp: u32, selection_atom: u32, manager_xid: u32) -> [u32; 5] {
    [timestamp, selection_atom, manager_xid, 0, 0]
}

/// Data words for the `_XEMBED` `XEMBED_EMBEDDED_NOTIFY` message sent to a
/// newly docked icon window once it has been reparented into `container_xid`.
pub fn xembed_embedded_notify_data(container_xid: u32, xembed_version: u32) -> [u32; 5] {
    [0, XEMBED_EMBEDDED_NOTIFY, 0, container_xid, xembed_version]
}

/// Extract the icon window id from a `_NET_SYSTEM_TRAY_OPCODE`
/// `ClientMessage`'s data words, if it is a dock request.
pub fn parse_dock_request(data: [u32; 5]) -> Option<u32> {
    if data[1] == SYSTEM_TRAY_REQUEST_DOCK {
        Some(data[2])
    } else {
        None
    }
}
```

```rust
/// Start the tray thread. Returns a command sender and event receiver; if no
/// X11 connection is available, or the tray selection is already owned by
/// another process, the thread logs once and exits - the channels stay
/// open but nothing is ever sent or received.
pub fn spawn(panel_height: i32) -> (mpsc::Sender<TrayCmd>, async_channel::Receiver<TrayEvent>) {
    let (cmd_tx, cmd_rx) = mpsc::channel::<TrayCmd>();
    let (evt_tx, evt_rx) = async_channel::unbounded::<TrayEvent>();
    std::thread::Builder::new()
        .name("opusdm-panel-systray".into())
        .spawn(move || {
            if let Err(e) = run(panel_height, cmd_rx, evt_tx) {
                eprintln!("opusdm-panel: system tray stopped: {e}");
            }
        })
        .expect("spawn systray thread");
    (cmd_tx, evt_rx)
}

fn run(
    panel_height: i32,
    cmd_rx: mpsc::Receiver<TrayCmd>,
    tx: async_channel::Sender<TrayEvent>,
) -> Result<(), Box<dyn std::error::Error>> {
    let (conn, screen_num) = x11rb::connect(None)?;
    let root = conn.setup().roots[screen_num].root;
    let atoms = Atoms::new(&conn)?.reply()?;

    let selection_name = format!("_NET_SYSTEM_TRAY_S{screen_num}");
    let selection_atom = conn.intern_atom(false, selection_name.as_bytes())?.reply()?.atom;

    let owner = conn.get_selection_owner(selection_atom)?.reply()?.owner;
    if owner != 0 {
        eprintln!("opusdm-panel: system tray already running, tray disabled");
        return Ok(());
    }

    let manager = conn.generate_id()?;
    conn.create_window(
        x11rb::COPY_DEPTH_FROM_PARENT,
        manager,
        root,
        -1,
        -1,
        1,
        1,
        0,
        WindowClass::INPUT_OUTPUT,
        x11rb::protocol::xproto::COPY_FROM_PARENT,
        &CreateWindowAux::new(),
    )?;
    conn.set_selection_owner(manager, selection_atom, CURRENT_TIME)?;
    conn.change_property32(
        x11rb::protocol::xproto::PropMode::REPLACE,
        manager,
        atoms._NET_SYSTEM_TRAY_ORIENTATION,
        x11rb::protocol::xproto::AtomEnum::CARDINAL,
        &[0], // horizontal
    )?;
    let ev = ClientMessageEvent::new(
        32,
        root,
        atoms.MANAGER,
        manager_message_data(CURRENT_TIME, selection_atom, manager),
    );
    conn.send_event(false, root, EventMask::STRUCTURE_NOTIFY, ev)?;
    conn.change_window_attributes(
        manager,
        &ChangeWindowAttributesAux::new().event_mask(EventMask::STRUCTURE_NOTIFY),
    )?;
    conn.flush()?;

    let icon_size = icon_square_size(panel_height);
    let mut containers: HashMap<u32, u32> = HashMap::new();

    event_loop(&conn, root, &atoms, manager, icon_size, &mut containers, &cmd_rx, &tx)
}
```

```rust
/// Poll interval when there is no pending X event: fast enough that a
/// `TrayCmd::PlaceIcon` lands within one frame, cheap enough to idle at.
const POLL_INTERVAL: Duration = Duration::from_millis(16);

#[allow(clippy::too_many_arguments)]
fn event_loop(
    conn: &RustConnection,
    _root: Window,
    _atoms: &Atoms,
    _manager: Window,
    _icon_size: i32,
    containers: &mut HashMap<u32, u32>,
    cmd_rx: &mpsc::Receiver<TrayCmd>,
    _tx: &async_channel::Sender<TrayEvent>,
) -> Result<(), Box<dyn std::error::Error>> {
    loop {
        while let Some(event) = conn.poll_for_event()? {
            let _ = event; // dock/undock handling added in Task 3
        }
        match cmd_rx.try_recv() {
            Ok(TrayCmd::PlaceIcon { xid, x, y, w, h }) => place_icon(conn, containers, xid, x, y, w, h)?,
            Err(mpsc::TryRecvError::Empty) => std::thread::sleep(POLL_INTERVAL),
            Err(mpsc::TryRecvError::Disconnected) => return Ok(()),
        }
    }
}

/// Move/resize a docked icon's container window. A no-op if `xid` isn't
/// currently docked (e.g. it was removed just before the command arrived).
fn place_icon(
    conn: &RustConnection,
    containers: &HashMap<u32, u32>,
    xid: u32,
    x: i32,
    y: i32,
    w: i32,
    h: i32,
) -> Result<(), Box<dyn std::error::Error>> {
    let Some(&container) = containers.get(&xid) else { return Ok(()) };
    conn.configure_window(
        container,
        &x11rb::protocol::xproto::ConfigureWindowAux::new().x(x).y(y).width(w as u32).height(h as u32),
    )?;
    conn.flush()?;
    Ok(())
}
```

```rust
/// reparent the client's icon into it, complete the XEmbed handshake, and

/// misbehaving client can't take down the tray thread.
fn dock_icon(

    atoms: &Atoms,
    containers: &mut HashMap<u32, u32>,
    root: Window,
    icon_size: i32,
    icon_xid: u32,
    tx: &async_channel::Sender<TrayEvent>,
) {
    let run = || -> Result<(), Box<dyn std::error::Error>> {
        let container = conn.generate_id()?;
        conn.create_window(
            x11rb::COPY_DEPTH_FROM_PARENT,
            container,
            root,
            0,
            0,
            icon_size.max(1) as u16,
            icon_size.max(1) as u16,
            0,
            WindowClass::INPUT_OUTPUT,

            icon_xid,

        )?;

                .height(icon_size.max(1) as u32),

            32,
            icon_xid,
            atoms._XEMBED,
            xembed_embedded_notify_data(container, 0),
        );
        conn.send_event(false, icon_xid, EventMask::NO_EVENT, ev)?;
        conn.map_window(icon_xid)?;
        conn.map_window(container)?;
        conn.flush()?;
        Ok(())

    match run() {
        Ok(()) => {
            containers.insert(icon_xid, 0); // placeholder, replaced below
        }
        Err(e) => {
            eprintln!("opusdm-panel: cannot dock tray icon {icon_xid}: {e}");
            return;
        }
    }
    let _ = tx.send_blocking(TrayEvent::IconDocked(icon_xid));
}

/// Destroy `icon_xid`'s container (if any tracked) and report its removal.
fn undock_icon(
    conn: &RustConnection,
    containers: &mut HashMap<u32, u32>,
    icon_xid: u32,
    tx: &async_channel::Sender<TrayEvent>,
) {
    if let Some(container) = containers.remove(&icon_xid) {
        let _ = conn.destroy_window(container);
        let _ = conn.flush();
        let _ = tx.send_blocking(TrayEvent::IconRemoved(icon_xid));
    }
}
```

```rust
fn event_loop(
    conn: &RustConnection,
    root: Window,
    atoms: &Atoms,
    manager: Window,
    icon_size: i32,
    containers: &mut HashMap<u32, u32>,
    cmd_rx: &mpsc::Receiver<TrayCmd>,
    tx: &async_channel::Sender<TrayEvent>,
) -> Result<(), Box<dyn std::error::Error>> {
    loop {
        while let Some(event) = conn.poll_for_event()? {
            match event {
                Event::ClientMessage(e)
                    if e.window == manager && e.type_ == atoms._NET_SYSTEM_TRAY_OPCODE =>
                {
                    if let Some(icon_xid) = parse_dock_request(e.data.as_data32()) {
                        dock_icon(conn, atoms, containers, root, icon_size, icon_xid, tx);
                    }
                }
                Event::DestroyNotify(e) if containers.contains_key(&e.window) => {
                    undock_icon(conn, containers, e.window, tx);
                }
                Event::UnmapNotify(e) if containers.contains_key(&e.window) => {
                    undock_icon(conn, containers, e.window, tx);
                }
                Event::ReparentNotify(e)
                    if containers.get(&e.window).is_some_and(|c| *c != e.parent) =>
                {
                    undock_icon(conn, containers, e.window, tx);
                }
                _ => {}
            }
        }
        match cmd_rx.try_recv() {
            Ok(TrayCmd::PlaceIcon { xid, x, y, w, h }) => place_icon(conn, containers, xid, x, y, w, h)?,
            Err(mpsc::TryRecvError::Empty) => std::thread::sleep(POLL_INTERVAL),
            Err(mpsc::TryRecvError::Disconnected) => return Ok(()),
        }
    }
}
```

```rust
//! The docked-icon placeholder strip: one fixed-size square per currently
//! docked tray icon, in dock order. Each square reserves screen space; the
//! real pixels are the client's own X window, drawn directly on top by the
//! X server once `systray.rs` places its container there - see `update`
//! and (positioning) the follow-up in this file's `reposition_now`.

use gtk4 as gtk;
use gtk::prelude::*;
use std::cell::{Cell, RefCell};
use std::collections::HashMap;
use std::rc::Rc;
use std::sync::mpsc::Sender;

use crate::systray::TrayCmd;

pub struct Tray {
    root: gtk::Box,
    icon_size: i32,
    cmd_tx: Sender<TrayCmd>,
    /// Dock order, mirrors what `update` was last called with.
    order: RefCell<Vec<u32>>,
    /// One placeholder square per docked xid, keyed the same way.
    placeholders: RefCell<HashMap<u32, gtk::Box>>,
    /// The owning bar's root-screen position, set once at construction by
    /// `build_bar_window` (see `lib.rs`) and never changed after (the panel
    /// doesn't move without a full rebuild, which rebuilds the Tray too).
    origin: Cell<(i32, i32)>,
}

impl Tray {
    /// Build an empty tray strip. `icon_size` is `systray::icon_square_size`
    /// applied to the panel height; `cmd_tx` is the sender half returned by
    /// `systray::spawn`.
    pub fn new(icon_size: i32, cmd_tx: Sender<TrayCmd>) -> Rc<Self> {
        let root = gtk::Box::new(gtk::Orientation::Horizontal, 4);
        root.set_valign(gtk::Align::Center);
        Rc::new(Tray {
            root,
            icon_size,
            cmd_tx,
            order: RefCell::new(Vec::new()),
            placeholders: RefCell::new(HashMap::new()),
            origin: Cell::new((0, 0)),
        })
    }

    pub fn widget(&self) -> &gtk::Widget {
        self.root.upcast_ref()
    }

    /// Record the bar's root-screen origin, used to translate placeholder
    /// bounds into absolute coordinates when placing real icon windows.
    pub fn set_origin(&self, x: i32, y: i32) {
        self.origin.set((x, y));
    }

    /// Reconcile the displayed placeholders with `order` (the current dock
    /// order from `TrayEvent`s folded into `PanelState`). Adds a square for
    /// every xid not yet shown, removes one for every xid no longer docked,
    /// preserving relative order for the rest.
    pub fn update(self: &Rc<Self>, order: &[u32]) {
        if *self.order.borrow() == order {
            return;
        }

        let mut placeholders = self.placeholders.borrow_mut();
        let previous: Vec<u32> = self.order.borrow().clone();

        for xid in &previous {
            if !order.contains(xid) {
                if let Some(square) = placeholders.remove(xid) {
                    self.root.remove(&square);
                }
            }
        }
        for &xid in order {
            if !placeholders.contains_key(&xid) {
                let square = gtk::Box::new(gtk::Orientation::Horizontal, 0);
                square.set_content_width(self.icon_size);
                square.set_content_height(self.icon_size);
                self.root.append(&square);
                placeholders.insert(xid, square);
            }
        }
        drop(placeholders);

        *self.order.borrow_mut() = order.to_vec();
    }
}
```

```rust
/// Recompute every docked icon's absolute screen rect from its
/// placeholder's current layout and tell `systray.rs` to move the real
/// window there. Safe to call any time the placeholders are realized;
/// a placeholder with no allocation yet (bounds unavailable) is skipped -
/// the next reposition pass (next `update`, or the panel's settle-delay
/// timers) will place it once layout has run.
pub fn reposition_now(&self) {
    let (origin_x, origin_y) = self.origin.get();
    let placeholders = self.placeholders.borrow();
    for (&xid, square) in placeholders.iter() {
        let Some(bounds) = square.compute_bounds(&self.root) else { continue };
        let x = origin_x + bounds.x() as i32;
        let y = origin_y + bounds.y() as i32;
        let w = bounds.width() as i32;
        let h = bounds.height() as i32;
        let _ = self.cmd_tx.send(TrayCmd::PlaceIcon { xid, x, y, w, h });
    }
}
```
