> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A Viewer window for the selected files with text, ANSI (CP437 and colour codes) and hex modes, SmartRead, in-file search, paging through several files, and an image slideshow that can mark pictures for deletion (F-16, F-17).

**Architecture:** Pure, tested modules (`ansi`, `viewer_search`, `slideshow`, `viewer_mode`, `viewer_load`) hold every decision; `viewer.rs` is a thin GTK window that loads on a thread and renders. Quick Look (`preview.rs`) is not changed in behaviour; it only exposes the file-kind detection the Viewer shares.

**Tech Stack:** Rust workspace, GTK4 (`TextView`/`TextTag`, `Picture`).

**Spec:** `docs/superpowers/specs/2026-09-29-viewer-design.md`

## Global Constraints

- Code and comments in English. Never use the long dash character; use `-`.
- Constants in UPPERCASE with `_`. Every function and method gets a doc comment (`///` for public ones).
- Exit conditions at the top of a function, one-liners where possible.
- Text files end with an empty line.
- Commit after each task with a meaningful message, only the files you changed. Do NOT push. Do NOT add AI attribution lines. Never use `--no-verify`. Do not disable tests.
- Read caps are constants: text and ANSI `VIEWER_TEXT_MAX` = 16 MiB, hex `VIEWER_HEX_MAX` = 1 MiB; Quick Look keeps 256 KiB. Making them settings is in `NEXT-PHASE.md`, not here.
- The file list is the selected files only (directories skipped); with no selection, the file under the cursor. Show keeps only the images among them; one selected image shows just that image.
- Nothing is deleted before the slideshow confirmation; the delete goes through `job_submit::submit_job(Op::Delete, ...)`.
- Quick Look and its keys are unchanged.

## Review Focus

1. ANSI input with a truncated escape at the end, a lone ESC, or unknown CSI sequences never panics and never leaves escape bytes in the text (Task 1 tests).
2. CP437 art is invalid UTF-8: SmartRead must choose ANSI for it (ESC[ in the head) and not Hex; plain text under `Text` decodes lossily instead of failing (Tasks 3 and 4 tests).
3. Search offsets are character offsets (GTK uses characters, not bytes) on non-ASCII text; an empty query clears the highlights (Task 2 tests).
4. A file larger than its cap shows the "showing the first N" notice, a file exactly at the cap does not (Task 4 tests).
5. Slideshow: closing with "Keep" deletes nothing; unmarking a picture removes it from the list to delete; only marked files are deleted (Tasks 2 and 6 tests).

const CP437_LOW: &str = " \u{263A}\u{263B}\u{2665}\u{2666}\u{2663}\u{2660}\u{2022}\u{25D8}\u{25CB}\u{25D9}\u{2642}\u{2640}\u{266A}\u{266B}\u{263C}\u{25BA}\u{25C4}\u{2195}\u{203C}\u{B6}\u{A7}\u{25AC}\u{21A8}\u{2191}\u{2193}\u{2192}\u{2190}\u{221F}\u{2194}\u{25B2}\u{25BC}";

/// The character CP437 shows for byte `b`.
pub fn cp437_char(b: u8) -> char {
    match b {
        0x00..=0x1F => CP437_LOW.chars().nth(b as usize).unwrap_or(' '),
        0x20..=0x7E => b as char,
        0x7F => '\u{2302}',
        _ => CP437_HIGH.chars().nth((b - 0x80) as usize).unwrap_or(' '),
    }
}

/// Decode CP437 bytes: newlines are kept, carriage returns dropped.
pub fn decode_cp437(bytes: &[u8]) -> String {
    bytes
        .iter()
        .filter(|&&b| b != b'\r')
        .map(|&b| if b == b'\n' { '\n' } else { cp437_char(b) })
        .collect()
}

/// A run of text with one style. Offsets are characters of [`AnsiDoc::text`].
#[derive(Clone, Debug, PartialEq, Eq)]
pub struct Span {
    pub start: usize,
    pub end: usize,
    /// Palette index, already brightened for bold.
    pub fg: Option<u8>,
    /// Palette index.
    pub bg: Option<u8>,
    pub bold: bool,
}

/// Decoded text plus the styled runs.
#[derive(Clone, Debug, PartialEq, Eq)]
pub struct AnsiDoc {
    pub text: String,
    pub spans: Vec<Span>,
}

/// The style being applied while parsing.
#[derive(Clone, Copy, Default)]
struct Style {
    fg: Option<u8>,
    bg: Option<u8>,
    bold: bool,
}

impl Style {
    /// Foreground as shown: bold brightens a normal colour.
    fn effective_fg(&self) -> Option<u8> {
        match self.fg {
            Some(c) if self.bold && c < 8 => Some(c + 8),
            other => other,
        }
    }

    /// Apply the parameters of one `ESC [ ... m` sequence.
    fn apply_sgr(&mut self, params: &str) {
        for p in params.split(';') {
            match p.parse::<u32>().unwrap_or(0) {
                0 => *self = Style::default(),
                1 => self.bold = true,
                22 => self.bold = false,
                n @ 30..=37 => self.fg = Some((n - 30) as u8),
                n @ 90..=97 => self.fg = Some((n - 90 + 8) as u8),
                39 => self.fg = None,
                n @ 40..=47 => self.bg = Some((n - 40) as u8),
                n @ 100..=107 => self.bg = Some((n - 100 + 8) as u8),
                49 => self.bg = None,
                _ => {}
            }
        }
    }
}

/// Close the run `start..end` in `style`, if it has any styling.
fn flush(spans: &mut Vec<Span>, start: usize, end: usize, style: &Style) {
    if end <= start {
        return;
    }
    let fg = style.effective_fg();
    if fg.is_none() && style.bg.is_none() && !style.bold {
        return;
    }
    spans.push(Span { start, end, fg, bg: style.bg, bold: style.bold });
}

/// Parse ANSI art: CP437 text with SGR colours and cursor-forward. Every
/// other escape sequence is skipped; a truncated one at the end is dropped.
pub fn parse_ansi(bytes: &[u8]) -> AnsiDoc {
    let mut text = String::new();
    let mut chars = 0usize;
    let mut spans = Vec::new();
    let mut style = Style::default();
    let mut span_start = 0usize;
    let mut i = 0usize;
    while i < bytes.len() {
        let b = bytes[i];
        if b == 0x1A {
            break;
        }
        if b == b'\r' {
            i += 1;
            continue;
        }
        if b == 0x1B {
            if bytes.get(i + 1) != Some(&b'[') {
                i += 1;
                continue;
            }
            // CSI: parameter and intermediate bytes, then a final byte.
            let Some(rel) = bytes[i + 2..].iter().position(|c| (0x40..=0x7E).contains(c)) else { break };
            let end = i + 2 + rel;
            let params = String::from_utf8_lossy(&bytes[i + 2..end]).into_owned();
            match bytes[end] {
                b'm' => {
                    flush(&mut spans, span_start, chars, &style);
                    style.apply_sgr(&params);
                    span_start = chars;
                }
                b'C' => {
                    let n = params.parse::<usize>().unwrap_or(1).max(1);
                    text.extend(std::iter::repeat_n(' ', n));
                    chars += n;
                }
                _ => {}
            }
            i = end + 1;
            continue;
        }
        text.push(if b == b'\n' { '\n' } else { cp437_char(b) });
        chars += 1;
        i += 1;
    }
    flush(&mut spans, span_start, chars, &style);
    AnsiDoc { text, spans }
}

/// Fold a character for case-insensitive comparison, one character to one
/// character so offsets stay aligned with the original text.
fn fold(c: char) -> char {
    c.to_lowercase().next().unwrap_or(c)
}

/// Every non-overlapping occurrence of `query` in `text`, ignoring case, as
/// half-open ranges of character offsets (the unit GTK text buffers use).
pub fn find_matches(text: &str, query: &str) -> Vec<(usize, usize)> {
    let needle: Vec<char> = query.chars().map(fold).collect();
    if needle.is_empty() {
        return Vec::new();
    }
    let haystack: Vec<char> = text.chars().map(fold).collect();
    let mut found = Vec::new();
    let mut i = 0;
    while i + needle.len() <= haystack.len() {
        if haystack[i..i + needle.len()] == needle[..] {
            found.push((i, i + needle.len()));
            i += needle.len();
        } else {
            i += 1;
        }
    }
    found
}

/// The match after (`forward`) or before `current`, wrapping around. With no
/// current match it starts at the first (forward) or the last (backward).
pub fn step(current: Option<usize>, count: usize, forward: bool) -> Option<usize> {
    if count == 0 {
        return None;
    }
    Some(match (current, forward) {
        (None, true) => 0,
        (None, false) => count - 1,
        (Some(i), true) => (i + 1) % count,
        (Some(i), false) => (i + count - 1) % count,
    })
}

use std::path::{Path, PathBuf};

/// The pictures marked for deletion, in marking order.
#[derive(Default)]
pub struct Marks {
    files: Vec<PathBuf>,
}

impl Marks {
    /// No marks.
    pub fn new() -> Self {
        Self::default()
    }

    /// Mark `path`, or unmark it if it was marked. True when it is now marked.
    pub fn toggle(&mut self, path: PathBuf) -> bool {
        if let Some(pos) = self.files.iter().position(|p| *p == path) {
            self.files.remove(pos);
            return false;
        }
        self.files.push(path);
        true
    }

    /// Whether `path` is marked.
    pub fn is_marked(&self, path: &Path) -> bool {
        self.files.iter().any(|p| p == path)
    }

    /// The marked files, in marking order.
    pub fn list(&self) -> Vec<PathBuf> {
        self.files.clone()
    }

    /// How many files are marked.
    pub fn len(&self) -> usize {
        self.files.len()
    }

    /// True when nothing is marked.
    pub fn is_empty(&self) -> bool {
        self.files.is_empty()
    }
}

/// Classify a file from its lower-case extension and its first bytes: the
/// extension decides for archives, pictures and known text types; otherwise
/// the first 512 bytes decide between text (no NUL, valid UTF-8) and binary.
pub fn kind_of(ext: &str, head: &[u8]) -> FileKind {
    if crate::archive::ARCHIVE_EXTS.contains(&ext) {
        return FileKind::Archive;
    }
    if IMAGE_EXTS.contains(&ext) {
        return FileKind::Image;
    }
    if TEXT_EXTS.contains(&ext) {
        return FileKind::Text;
    }
    let probe = &head[..head.len().min(512)];
    if !probe.is_empty() && !probe.contains(&0) && std::str::from_utf8(probe).is_ok() {
        return FileKind::Text;
    }
    FileKind::Binary
}

/// Detect the kind of file based on extension and content.
pub fn detect_file_kind(path: &Path) -> FileKind {
    let ext = path.extension().and_then(|e| e.to_str()).unwrap_or("").to_lowercase();
    // Only an unknown extension needs the content probe.
    let mut head = [0u8; 512];
    let n = if kind_of(&ext, &[]) == FileKind::Binary {
        File::open(path).and_then(|mut f| f.read(&mut head)).unwrap_or(0)
    } else {
        0
    };
    kind_of(&ext, &head[..n])
}

/// How many leading bytes SmartRead looks at.
pub const SNIFF_LEN: usize = 4096;

/// Extensions that mean ANSI art whatever the content.
const ANSI_EXTS: [&str; 3] = ["ans", "diz", "asc"];

/// What the user asked for.
#[derive(Clone, Copy, Debug, PartialEq, Eq)]
pub enum Mode {
    /// Pick by extension and content.
    Smart,
    Text,
    Ansi,
    Hex,
}

/// What a file is actually shown as.
#[derive(Clone, Copy, Debug, PartialEq, Eq)]
pub enum Resolved {
    Image,
    Text,
    Ansi,
    Hex,
}

/// True when `head` holds a CSI escape sequence (`ESC [`).
fn has_csi(head: &[u8]) -> bool {
    head.windows(2).any(|w| w == b"\x1b[")
}

/// Decide how to show a file. Explicit modes are obeyed; `Smart` chooses
/// picture, ANSI (art extension or an `ESC [` in the first `SNIFF_LEN` bytes,
/// checked before the text probe because CP437 art is not valid UTF-8), text
/// or hex.
pub fn resolve(mode: Mode, ext: &str, head: &[u8]) -> Resolved {
    match mode {
        Mode::Text => Resolved::Text,
        Mode::Ansi => Resolved::Ansi,
        Mode::Hex => Resolved::Hex,
        Mode::Smart => {
            let ext = ext.to_lowercase();
            let head = &head[..head.len().min(SNIFF_LEN)];
            if IMAGE_EXTS.contains(&ext.as_str()) {
                Resolved::Image
            } else if ANSI_EXTS.contains(&ext.as_str()) || has_csi(head) {
                Resolved::Ansi
            } else if kind_of(&ext, head) == FileKind::Text {
                Resolved::Text
            } else {
                Resolved::Hex
            }
        }
    }
}

/// The files the Viewer pages through: the selection without directories, or
/// the file under the cursor when nothing is selected.
pub fn viewer_files(selected: &[PathBuf], cursor: Option<&Path>) -> Vec<PathBuf> {
    if !selected.is_empty() {
        return selected.iter().filter(|p| !p.is_dir()).cloned().collect();
    }
    cursor.filter(|p| !p.is_dir()).map(|p| vec![p.to_path_buf()]).unwrap_or_default()
}

/// The pictures among `files`, in order.
pub fn image_files(files: &[PathBuf]) -> Vec<PathBuf> {
    files
        .iter()
        .filter(|p| {
            let ext = p.extension().and_then(|e| e.to_str()).unwrap_or("").to_lowercase();
            IMAGE_EXTS.contains(&ext.as_str())
        })
        .cloned()
        .collect()
}

use crate::ansi::{parse_ansi, AnsiDoc};
use crate::model::format_size;
use crate::preview::generate_hex_dump;
use crate::viewer_mode::{resolve, Mode, Resolved, SNIFF_LEN};
use std::fs::File;
use std::io::{self, Read};
use std::path::Path;

/// Most bytes of a file shown in text or ANSI mode.
pub const VIEWER_TEXT_MAX: u64 = 16 * 1024 * 1024;

/// Most bytes of a file shown in hex mode.
pub const VIEWER_HEX_MAX: u64 = 1024 * 1024;

/// A file ready to render; plain data, so it can cross from the loader thread.
#[derive(Debug)]
pub enum ViewData {
    Text { meta: String, text: String },
    Ansi { meta: String, doc: AnsiDoc },
    Hex { meta: String, text: String },
    Image { bytes: Vec<u8>, meta: String },
    Error { message: String },
}

/// The first `cap` bytes of `path`.
fn read_prefix(path: &Path, cap: u64) -> io::Result<Vec<u8>> {
    let mut buf = Vec::new();
    File::open(path)?.take(cap).read_to_end(&mut buf)?;
    Ok(buf)
}

/// " - showing the first N" when the file is bigger than the cap, else empty.
fn truncation_note(size: u64, cap: u64) -> String {
    if size > cap { format!("  \u{2022}  showing the first {}", format_size(false, cap)) } else { String::new() }
}

/// Load `path` for the Viewer with the standard caps.
pub fn load(path: &Path, mode: Mode) -> ViewData {
    load_with_caps(path, mode, VIEWER_TEXT_MAX, VIEWER_HEX_MAX)
}

/// Load `path`, reading at most `text_cap` bytes for text and ANSI and
/// `hex_cap` for hex. Blocking: call it off the GTK thread.
pub fn load_with_caps(path: &Path, mode: Mode, text_cap: u64, hex_cap: u64) -> ViewData {
    let error = |e: io::Error| ViewData::Error { message: format!("Cannot open: {e}") };
    let size = match std::fs::metadata(path) {
        Ok(m) => m.len(),
        Err(e) => return error(e),
    };
    let head = match read_prefix(path, SNIFF_LEN as u64) {
        Ok(h) => h,
        Err(e) => return error(e),
    };
    let ext = path.extension().and_then(|e| e.to_str()).unwrap_or("").to_lowercase();
    let size_str = format_size(false, size);
    match resolve(mode, &ext, &head) {
        Resolved::Image => match std::fs::read(path) {
            Ok(bytes) => ViewData::Image { bytes, meta: format!("{size_str}  \u{2022}  {}", ext.to_uppercase()) },
            Err(e) => error(e),
        },
        Resolved::Text => match read_prefix(path, text_cap) {
            Ok(buf) => {
                let text = String::from_utf8_lossy(&buf).into_owned();
                let meta = format!("{} lines  \u{2022}  {size_str}{}", text.lines().count(), truncation_note(size, text_cap));
                ViewData::Text { meta, text }
            }
            Err(e) => error(e),
        },
        Resolved::Ansi => match read_prefix(path, text_cap) {
            Ok(buf) => {
                let meta = format!("ANSI  \u{2022}  {size_str}{}", truncation_note(size, text_cap));
                ViewData::Ansi { meta, doc: parse_ansi(&buf) }
            }
            Err(e) => error(e),
        },
        Resolved::Hex => match read_prefix(path, hex_cap) {
            Ok(buf) => {
                let meta = format!("Hex  \u{2022}  {size_str}{}", truncation_note(size, hex_cap));
                ViewData::Hex { meta, text: generate_hex_dump(&buf) }
            }
            Err(e) => error(e),
        },
    }
}

        root.append(&search_bar);

        let content = gtk::Box::new(gtk::Orientation::Vertical, 0);
        content.set_vexpand(true);
        content.set_hexpand(true);
        root.append(&content);
        window.set_child(Some(&root));

        let viewer = Rc::new(Self {
            ui: ui.clone(),
            window,
            files,
            index: Cell::new(0),
            mode: Cell::new(mode),
            show,
            generation: Cell::new(0),
            title,
            meta,
            content,
            text_view: RefCell::new(None),
            search_bar,
            search_entry: search_entry.clone(),
            search_count,
            matches: RefCell::new(Vec::new()),
            current: Cell::new(None),
        });

        {
            let v = viewer.clone();
            search_entry.connect_changed(move |_| v.run_search());
        }
        {
            let v = viewer.clone();
            search_entry.connect_activate(move |_| v.step_match(true));
        }
        {
            let v = viewer.clone();
            next_btn.connect_clicked(move |_| v.step_match(true));
        }
        {

    /// True while the focus is in a text entry, where letters are text.
    fn typing(&self) -> bool {
        self.window.focus().is_some_and(|w| w.is::<gtk::Editable>())
    }

    /// Keys of the window. Runs in the capture phase so Shift+Enter in the
    /// search entry can step backwards.
    fn install_keys(self: &Rc<Self>) {
        let v = self.clone();
        let ctrl = gtk::EventControllerKey::new();
        ctrl.set_propagation_phase(gtk::PropagationPhase::Capture);
        ctrl.connect_key_pressed(move |_, key, _, state| {
            let with_ctrl = state.contains(gdk::ModifierType::CONTROL_MASK);
            let shift = state.contains(gdk::ModifierType::SHIFT_MASK);
            if key == gdk::Key::Escape {
                if v.search_bar.is_visible() {
                    v.search_bar.set_visible(false);
                    if let Some(view) = v.text_view.borrow().as_ref() {
                        view.grab_focus();
                    }
                } else {
                    v.window.close();
                }
                return glib::Propagation::Stop;
            }
            if with_ctrl && matches!(key, gdk::Key::f | gdk::Key::F) {
                v.search_bar.set_visible(true);
                v.search_entry.grab_focus();
                return glib::Propagation::Stop;
            }
            if key == gdk::Key::F3 {
                v.step_match(!shift);
                return glib::Propagation::Stop;
            }
            if v.typing() {
                let backwards = shift && matches!(key, gdk::Key::Return | gdk::Key::KP_Enter);
                if backwards {
                    v.step_match(false);
                    return glib::Propagation::Stop;
                }
                return glib::Propagation::Proceed;
            }
            match key {
                gdk::Key::n | gdk::Key::N => v.go(1),
                gdk::Key::p | gdk::Key::P => v.go(-1),
                gdk::Key::Right if v.showing_image() => v.go(1),
                gdk::Key::Left if v.showing_image() => v.go(-1),
                gdk::Key::t if !v.show => v.set_mode(Mode::Text),
                gdk::Key::a if !v.show => v.set_mode(Mode::Ansi),
                gdk::Key::x if !v.show => v.set_mode(Mode::Hex),
                gdk::Key::s if !v.show => v.set_mode(Mode::Smart),
                _ => return glib::Propagation::Proceed,
            }
            glib::Propagation::Stop
        });
        self.window.add_controller(ctrl);
    }

    /// True when the current file is shown as a picture (no text view).
    fn showing_image(&self) -> bool {
        self.text_view.borrow().is_none()
    }

    /// Move `delta` files, wrapping around.
    fn go(self: &Rc<Self>, delta: isize) {
        let n = self.files.len() as isize;
        let next = (self.index.get() as isize + delta).rem_euclid(n);
        self.index.set(next as usize);
        self.show_file();
    }

    /// Switch the mode and reload the current file.
    fn set_mode(self: &Rc<Self>, mode: Mode) {
        self.mode.set(mode);
        self.show_file();
    }

    /// Load the current file on a thread and render it when it arrives.
    fn show_file(self: &Rc<Self>) {
        let path = self.files[self.index.get()].clone();
        let name = path.file_name().map(|n| n.to_string_lossy().into_owned()).unwrap_or_default();
        self.title.set_text(&format!("{}/{}  {}", self.index.get() + 1, self.files.len(), name));
        self.window.set_title(Some(&format!("{}: {name}", if self.show { "Show" } else { "Viewer" })));
        self.meta.set_text("Loading\u{2026}");
        self.clear_content();

        let gen = self.generation.get() + 1;
        self.generation.set(gen);
        let mode = self.mode.get();
        let (tx, rx) = async_channel::bounded::<ViewData>(1);
        let path_for_thread = path.clone();
        std::thread::spawn(move || {
            let _ = tx.send_blocking(load(&path_for_thread, mode));
        });
        let this = self.clone();
        glib::spawn_future_local(async move {
            let Ok(data) = rx.recv().await else { return };
            if this.generation.get() != gen {
                return;
            }
            this.apply(data);
        });
    }

    /// Remove what the content area shows.
    fn clear_content(&self) {
        *self.text_view.borrow_mut() = None;
        while let Some(child) = self.content.first_child() {
            self.content.remove(&child);
        }
    }

    /// Render loaded data.
    fn apply(self: &Rc<Self>, data: ViewData) {
        self.clear_content();
        match data {
            ViewData::Text { meta, text } => {
                self.meta.set_text(&meta);
                self.render_text(&text, None, gtk::WrapMode::WordChar);
            }
            ViewData::Ansi { meta, doc } => {
                self.meta.set_text(&meta);
                self.render_text(&doc.text, Some(&doc), gtk::WrapMode::None);
            }
            ViewData::Hex { meta, text } => {
                self.meta.set_text(&meta);
                self.render_text(&text, None, gtk::WrapMode::None);
            }
            ViewData::Image { bytes, meta } => self.render_image(&bytes, &meta),
            ViewData::Error { message } => {
                self.meta.set_text("Error");
                let label = gtk::Label::new(Some(&message));
                label.set_margin_top(20);
                self.content.append(&label);
            }
        }
        self.run_search();
    }

    /// Show `text` in a read-only monospace view, colouring it with `ansi`.
    fn render_text(&self, text: &str, ansi: Option<&AnsiDoc>, wrap: gtk::WrapMode) {
        let view = gtk::TextView::builder()
            .editable(false)
            .cursor_visible(false)
            .monospace(true)
            .wrap_mode(wrap)
            .left_margin(8)
            .right_margin(8)
            .top_margin(8)
            .bottom_margin(8)
            .build();
        let buffer = view.buffer();
        buffer.set_text(text);
        if let Some(doc) = ansi {
            apply_ansi_tags(&buffer, doc);
        }
        // Created last, so they win over the ANSI colours.
        let _ = buffer.create_tag(Some(MATCH_TAG), &[("background", &"#d4b106"), ("foreground", &"#000000")]);
        let _ = buffer.create_tag(Some(CURRENT_TAG), &[("background", &"#ff7a00"), ("foreground", &"#000000")]);
        let scroller = gtk::ScrolledWindow::builder().child(&view).vexpand(true).hexpand(true).build();
        self.content.append(&scroller);
        if !self.search_bar.is_visible() {
            view.grab_focus();
        }
        *self.text_view.borrow_mut() = Some(view);
    }

    /// Show a picture, falling back to its name and size if it cannot decode.
    fn render_image(&self, bytes: &[u8], meta: &str) {
        let picture = gtk::Picture::new();
        picture.set_can_shrink(true);
        picture.set_content_fit(gtk::ContentFit::Contain);
        picture.set_vexpand(true);
        picture.set_hexpand(true);
        let text = match gdk::Texture::from_bytes(&glib::Bytes::from(bytes)) {
            Ok(texture) => {
                let t = format!("{} \u{D7} {} px  \u{2022}  {meta}", texture.width(), texture.height());
                picture.set_paintable(Some(&texture));
                t
            }
            Err(_) => meta.to_string(),
        };
        self.meta.set_text(&text);
        self.content.append(&picture);
    }

    /// Highlight every match of the search text and move to the first.
    fn run_search(&self) {
        self.matches.borrow_mut().clear();
        self.current.set(None);
        let Some(view) = self.text_view.borrow().clone() else {
            self.search_count.set_text("");
            return;
        };
        let buffer = view.buffer();
        let (start, end) = buffer.bounds();
        buffer.remove_tag_by_name(MATCH_TAG, &start, &end);
        buffer.remove_tag_by_name(CURRENT_TAG, &start, &end);
        let query = self.search_entry.text().to_string();
        let found = find_matches(buffer.text(&start, &end, false).as_str(), &query);
        for (s, e) in &found {
            buffer.apply_tag_by_name(MATCH_TAG, &buffer.iter_at_offset(*s as i32), &buffer.iter_at_offset(*e as i32));
        }
        let first = step(None, found.len(), true);
        *self.matches.borrow_mut() = found;
        self.goto_match(first);
        if query.is_empty() {
            self.search_count.set_text("");
        }
    }

    /// Move the search to the next or previous match.
    fn step_match(&self, forward: bool) {
        let count = self.matches.borrow().len();
        self.goto_match(step(self.current.get(), count, forward));
    }

    /// Make match `index` the current one and scroll to it.
    fn goto_match(&self, index: Option<usize>) {
        let Some(view) = self.text_view.borrow().clone() else { return };
        let buffer = view.buffer();
        let (start, end) = buffer.bounds();
        buffer.remove_tag_by_name(CURRENT_TAG, &start, &end);
        self.current.set(index);
        let count = self.matches.borrow().len();
        let Some(i) = index else {
            self.search_count.set_text(if self.search_entry.text().is_empty() { "" } else { "0/0" });
            return;
        };
        let (s, e) = self.matches.borrow()[i];
        buffer.apply_tag_by_name(CURRENT_TAG, &buffer.iter_at_offset(s as i32), &buffer.iter_at_offset(e as i32));
        let mut iter = buffer.iter_at_offset(s as i32);
        view.scroll_to_iter(&mut iter, 0.1, false, 0.0, 0.0);
        self.search_count.set_text(&format!("{}/{count}", i + 1));
    }
}

/// Colour `buffer` from the spans of `doc`: a dark base, then one tag per
/// distinct style, created lazily.
fn apply_ansi_tags(buffer: &gtk::TextBuffer, doc: &AnsiDoc) {
    let base = buffer.create_tag(Some("ansi-base"), &[("foreground", &PALETTE[7]), ("background", &PALETTE[0])]);
    let (start, end) = buffer.bounds();
    if let Some(base) = base {
        buffer.apply_tag(&base, &start, &end);
    }
    let mut tags: HashMap<(Option<u8>, Option<u8>, bool), gtk::TextTag> = HashMap::new();
    for span in &doc.spans {
        let key = (span.fg, span.bg, span.bold);
        let tag = tags.entry(key).or_insert_with(|| {
            let tag = gtk::TextTag::new(None);
            if let Some(fg) = span.fg {
                tag.set_foreground(Some(PALETTE[fg as usize]));
            }
            if let Some(bg) = span.bg {
                tag.set_background(Some(PALETTE[bg as usize]));
            }
            if span.bold {
                tag.set_weight(700);
            }
            buffer.tag_table().add(&tag);
            tag
        });
        buffer.apply_tag(tag, &buffer.iter_at_offset(span.start as i32), &buffer.iter_at_offset(span.end as i32));
    }
}

    /// Ask before closing a slideshow that has marked pictures. Nothing is
    /// deleted unless the user picks Delete.
    fn install_close_guard(self: &Rc<Self>) {
        let v = self.clone();
        self.window.connect_close_request(move |_| {

                        files.clone(),
                        Some(ui.cwd_path()),
                        opusdm_ipc::JobOptions::default(),

                }
                viewer.closing.set(true);
                viewer.window.close();
            });
            glib::Propagation::Stop
        });
