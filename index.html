OpusDM apt repository

amd64. Use the suite of your Ubuntu release: resolute (26.04) or stonking (26.10). The suite stable is the legacy one and holds the 26.04 build.

sudo install -d -m 0755 /etc/apt/keyrings
sudo curl -fsSL https://fsoft72.github.io/opusdm/opusdm.gpg -o /etc/apt/keyrings/opusdm.gpg
echo "deb [signed-by=/etc/apt/keyrings/opusdm.gpg] https://fsoft72.github.io/opusdm $(. /etc/os-release; echo $VERSION_CODENAME) main" | sudo tee /etc/apt/sources.list.d/opusdm.list
sudo apt update
sudo apt install opusdm
